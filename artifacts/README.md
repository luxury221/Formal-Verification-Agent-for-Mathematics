# Local artifacts

This directory is intentionally present in a fresh checkout. Tests and the local
workbench create their own temporary files, ledgers and verification evidence here.

Generated content is ignored by Git. The published repository does not contain
the developer's research notebooks, imported articles, SQLite databases, model
credentials, runtime installations or historical proof artifacts. Historical
reports linked from development notes describe local runs and may refer to files
that are not part of this repository. Those reports are not fresh attestations.

Keep the relevant databases and proof files together when backing up a local
workspace. Do not import a historical report as current mathematical authority.
