# ADR-003：P0 证据和对齐规则

日期：2026-10-19。状态：采用。机器可读策略：`lean_workspace/evidence-policy.json`。

允许基础公理 `propext`、`Classical.choice`、`Quot.sound`；拒绝 `sorryAx`、`Lean.ofReduceBool` 及其他不在允许集合内的公理。模块新增公理即使未用于目标，也拒绝本轮严格晋升。未使用 helper 的占位也检查。该有限策略不代表已由外部形式化专家完成全面审核。

E3 只表示确切形式命题已检查。E4 另需匹配命题内容哈希与形式化内容哈希的具名对齐记录；缺少确认时保持 E3/UNKNOWN。反驳必须实际证明原目标的否定。

内部后端为每轮结果生成 HMAC-SHA256 回执，包含源、请求、日志哈希、命题/形式化/环境指纹和策略摘要。门禁重新核对工件，不能接收外部提供的 PASS 作为证据。密钥只在当前后端实例的进程内存中，持久日志提供审计与重新检查入口；没有声称实现跨进程公开可验证签名。

Mathlib 及基础库处于固定工具链的信任范围；后续需要记录实际导入工件的内容清单、生产签名和撤销传播。更改假设、结论、版本、工具链或策略，需要新检查。
