# ADR-013：自然数猜想的受控模型闭环

日期：2026-10-24。状态：已实施并验收接入功能；真实模型效果评测待用户配置。

用户选择先完成模型接入功能，稍后配置真实模型。现有两目标工作台保留，新增自然数猜想入口。没有配置时不请求模型、不伪装已具备生成能力。

首期允许用户输入新自然语言命题，由兼容 Chat Completions 的模型输出有界自然数公式树。服务端校验作用域、节点和整数预算，再确定性生成 Lean 陈述；不执行模型提供的 Lean 源、命令、导入或战术文本。候选必须由用户具名确认才允许搜索。

模型在固定原命题上提出证明或否定方向，以及有限策略（omega、simp、decide、自然数见证反例）。策略由受信模板生成，失败反馈供至多三次候选修复使用；不得改变命题或增加前提。每次成功必须经过既有隔离 Lean 检查、独立进程证明数据重放、公理门禁和内容封存。策略与公式工件随回执绑定。

模型配置及密钥只从本机忽略版本控制的配置读取，不经 HTTP 接收或返回。每次模型请求在独立进程内限制墙钟时间、输出大小，支持取消；禁止重定向。供应商用量及实际响应模型标识与生成文本分开记录，费用未配置时为未知。

猜想和事件保存在项目 SQLite 账本，原文、候选、确认、配置指纹与运行快照绑定。与原任务共享进程锁；崩溃恢复只标记中断，不从旧工件发布数学判断。取消或撤销确认后不发布 E4。历史报告核对文件摘要，明确不是当前环境新认证。

验收分别记录协议模拟和真实 Lean；本轮不配置真实模型，因此不能报告模型求解率。后续用真实服务在固定预算下评测。论文审稿、知识检索和训练仍在后续阶段。

专项25项、浏览器7项通过；253项覆盖在初次252通过及1项环境干扰后的独立复验中完成。过程及证据见 `docs/evaluation/idea-workflow-results.md`。
