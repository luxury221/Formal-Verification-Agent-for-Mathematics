# ADR-014：给定形式化目标的固定预算模型评测

日期：2026-10-24。状态：已实施并通过62项受影响回归；真实模型效果待用户配置。

用户选择先实现接入、稍后配置模型。此前的作者参考验收与猜想页面协议测试不能回答模型在相同预算下能解决多少题。新增独立命令，先提供可检查的评测计划，再在配置可用时执行真实模型策略评测。

每题使用已有 Nat 数据集的原文及项目作者映射的结构化形式化目标，最多一次模型请求、一次真实 Lean 候选检查及独立进程重放。沿用原评测数值预算：模型 30 秒、16,000 输入字符、2,048 输出 token、65,536 输出字节，Lean 两阶段共享 30 秒，环境内容核对另计。模型不能改写目标、注入 Lean 源或提高预算。该模式不执行反馈修复，不能直接与网页最多三次尝试的结果混算。

映射只接纳已封存数据集中18条确切参考陈述，不提供通用 Lean 解析器。`Nat.succ n` 显式映射为 `n + 1`，截断减法与全部前提保留。模型请求排除参考证明、方向标签与作者反例见证。完整映射仍是作者语义声明，不等于独立专家认证。

成功须经过既有 NativeLeanBackend、EvidenceGate 及作者映射的 E4 门禁，并匹配参考判断。失败、超时、拒绝作答均计入选定题目分母；取消或中断的整轮不出求解率。真实模型与 fixture 运行分别记账，后者的 model_solve_rate 始终为 null。失败请求可能已被供应商处理，单独记录请求尝试数、完整响应数、已知 token 与用量是否完整，费用保持 null。

整轮持有既有 worker 锁并传给子进程，防止与网页任务并行抢占。逐题保存请求、响应、结果、Lean 工件摘要与阶段报告；历史读取复核工件和聚合数据，不自动恢复、重试或重新授予证据。摘要不是持久签名，宿主用户和本机文件仍受信。

此评测只衡量**给定作者形式化目标后的证明/反例策略选择**。不衡量自然语言自动形式化、独立语义对齐、论文审稿、训练提升或任意数学能力。原作者证明不受四种策略限制，即便数值预算一致也不能据此宣称搜索能力公平等价。预留组保持显式 opt-in，并继续披露它并非独立盲测。

未增加依赖、模型权重、执行策略或受信 Lean 模板；现有运行封存不变。
