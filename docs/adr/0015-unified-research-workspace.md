# ADR-015：统一研究工作区与完整前端构造

- 日期：2026-10-25
- 状态：接受
- 依据：产品蓝图三种模式；用户要求优先完成美观的完整前端，查看整体构造。

## 决策

以暖白、墨绿、少量琥珀色及自绘数学 SVG 建立统一视觉系统。侧栏分为研究空间与研究工具，顶部提供真实本地记录搜索；手机改为导航抽屉。保留浏览器原生表单、对话框、焦点轮廓及减少动画偏好，不添加前端框架、CDN、外部字体或图标依赖。

根路径 `/` 成为研究总览；原固定目标验证迁到 `/verify`，其表单、证据读取及任务逻辑继续复用现有实现。`/ideas` 保留真实猜想流程。新增论文审查、知识图谱、评测中心、研究记录、产品全景和设置，共九个入口。共享 shell 与样式负责导航、搜索、弹窗、提示及响应布局；普通工作区页面按路径渲染，猜想和固定验证继续使用各自脚本。

## 数据与功能边界

- 总览、搜索与研究记录只读取现有猜想和任务的执行元数据，不把完成状态当成数学判断。详细结论继续由原报告接口核对工件后提供。
- 论文审查是布局预览，示例的命题与原证明分别保持未验证/未审查。可在当前浏览器会话整理纯文本草稿与笔记，或选择不超过 2 MB 的 txt/md/tex；不上传、不编译 LaTeX、不解析 PDF、不自动审稿。草稿转入猜想入口后仍需用户提交。
- 知识图谱与条目列表只显示明确标记的五个结构示例。节点可点击，但没有已入库知识、验证证据或撤销传播能力。
- 评测中心读取真实固定预算计划和最多二十条本机评测元数据；打开详情才调用既有完整性读取器核对工件。模拟记录明确标为非模型分数。启动评测继续使用 CLI，没有新增 HTTP 执行入口。
- 设置可在浏览器生成、复制或下载配置 JSON，不接收密钥、不写服务器配置、不尝试连接供应商。真实模型仍由用户稍后配置。
- 产品全景逐步解释问题、候选、语义确认、探索、严格验证及积累，分别标出现有功能、配置后可用及设计预览。

## 可信边界

新页面及两个只读评测接口沿用精确回环 Host、同源 Origin、CSRF、CSP 与 no-store。评测路径采用固定 ID 白名单，拒绝符号链接及超限/坏记录。列表不发布求解率或数学标签。没有修改 Lean、受信源生成器、证据政策、模板或运行封存；真实证明仍需要两阶段 Lean 与语义对齐。

本轮所有图形和样式由项目独立编写，无新增运行依赖或外部素材。未采用 Euler 非商业实现，也没有下载模型或发送用户研究资料。

## 取舍与验证

完整构造先交付可浏览界面；论文自动审查和知识入库继续按原蓝图推进，不能将设计示例解释为功能验收。sessionStorage 不提供跨浏览器或长期持久化；界面对此明确说明。

验证包括真实 Edge 的桌面/手机视口、导航与交互、草稿保留、真实历史读取、无密钥配置生成，以及受影响的 HTTP、猜想、评测读取和真实 Lean 回归。证据见 [前端验收](../evaluation/frontend-design-results.md)；页面与数据说明见 [工作区协议](../protocols/workspace-ui-v1.md)。
