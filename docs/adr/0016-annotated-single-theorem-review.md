# ADR-016：人工标注单定理的双通道真实审查

日期：2026-10-25。状态：接受。对应蓝图 3.1、3.3、13.1/C 与 MRA-024。

## 问题与决策

此前论文页只有阅读布局与会话草稿。命题可能成立而作者推理有缺口，不能用系统另外找到的证明替作者原证明背书。新增自然数单定理审查，分别返回 `claim_verdict` 和 `author_proof_verdict`，每一步保留原文行号与确切形式化义务。

用户仍选择稍后配置模型。本阶段使用人工标注的结构化公式、明确引用和受信策略计划；三个自有文本示例可以直接真实验证。自动提取论文、PDF 解析、自然语言步骤形式化及一般数学仍待后续。这里不是基于原文关键词的诊断，也不使用模型自述赋予结果。

## 义务与有效依赖

一份标注包含版本化文档、至多四个自然数变量、四项显式全局前提、结论、命题原文行号，以及至多四个作者证明步骤。每步给出原文行号、公式、仅指向更早步骤的引用和至多一次受限检查计划。前提没有自动补全；外部未验证引理、循环引用与自由 Lean 源不受支持。

命题通道检查 `∀变量, 全局前提 → 结论`。步骤通道检查 `∀变量, 全局前提 → 被引用步骤 → 当前步骤`；任何被引用步骤没有真实证明，就跳过依赖它的检查，不能当可信假设继续推演。全部作者步骤须通过，且最后一步确切陈述原结论，才发布作者步骤 `PROVED`。此结论只覆盖人工标注和具名确认的推理义务，不认证所有未标注的自然语言细节。

某一步义务的完整否定通过真实检查时，作者通道为 `GAP_FOUND`，报告具体行号、义务和核验的反例输入。最后一步没有陈述原结论时，单独标记结构性 `CONCLUSION_NOT_REACHED`，不称为数学反例。普通策略失败、超时或未检查依赖保持未闭合/未知，不据此指控作者错误。命题通道不受作者通道结果替代。

## 授权、调度与历史

先准备可见的义务计划，再由研究者具名确认全文、变量、前提、结论、行号及步骤引用。计划指纹绑定完整标注、每项目标和策略以及审查实现版本；任何变更都要求重新准备。确认者是本地姓名声明，不是账户认证。

SQLite 单独持久化审查、检查、事件和确认，复用现有 worker 独占锁及子进程锁继承。HTTP 后台与 CLI 使用相同队列。每义务只调用既有 Nat 编译器和四种受限策略，候选与独立进程重放共用 30 秒；最多五次检查，环境内容扫描另计。没有新增 Lean 模板、执行模式、模型调用或预算修复机会。

取消、撤销和崩溃恢复均不重新发布遗留检查结果。历史读取复核全部工件摘要；任何一项变化、实现协议变化或确认撤销，都停用两项对外结论。原始检查保留为历史。摘要不是持久签名，历史完整不代表当前环境新认证。

## 依赖与验收

仅使用既有 Python 标准库、SQLite、Nat 编译器、NativeLeanBackend 与 EvidenceGate。三个示例由项目独立编写；没有新依赖、第三方论文、模型权重或 Euler 实现。Lean、Mathlib、受信模板与证据政策不变，无需重新封存。

验收覆盖完整证明、真命题与错误作者步骤、缺条件的真实反例、策略失败、未验证依赖、版本漂移、幂等、取消/撤销、崩溃与工件篡改；还包括实际浏览器提交和双通道报告。协议见 [单定理审查](../protocols/paper-review-v1.md)，实测结果见 [验收记录](../evaluation/paper-review-results.md)。
