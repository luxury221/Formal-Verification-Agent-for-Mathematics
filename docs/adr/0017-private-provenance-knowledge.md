# ADR-017：私有知识索引、证明归档与依赖失效

日期：2026-10-25。状态：接受。对应蓝图 3.2、7.1/L1、8.2、13.1/L 与 MRA-025 首期。

## 决策与范围

知识页由结构示例改为真实本机私有知识库。首期从人工标注 Nat 单定理审查接收 PROVED/E4 义务，要求来源仍有效、完整工件一致及本地具名对齐记录。反驳、未知、未执行、未验证依赖、裸 PASS 或客户端自报 E4 均不能入库。命题的独立证明可在作者证明有缺口时单独入库，不为作者步骤背书。

先预览确切公式、来源版本/行号和步骤引用，再具名确认条目范围与私有保存权利。默认不共享、不训练，没有授权继承至模型服务。入库不运行模型或 Lean，不授予新认证；它索引已签发、当前仍可核对的历史证据。

每条固定 source review/key、原文版本、完整公式树及语法指纹、完整前提、审核者、公理、环境快照、证明回执和文件摘要。将已检查运行的 Lean 源、受限输入、证明数据、日志、回执和报告按原摘要复制到私有证明归档。来源与归档均须保持一致。语法相同但来源不同的证明保留独立出处；同一来源/步骤幂等去重，不宣称解决数学等价判定。新来源版本产生新条目，不就地改变已有陈述。

## 依赖与撤销

边由审查中实际标注且已验证的早期步骤引用生成，用户不能任意提交边。边表示作者推理的引用与保守使用条件，不声称等于 Lean 常量的最小依赖集。条目中保存的是完整条件义务，不能省略其前提而称为无条件引理。命题通道没有作者步骤边，撤销无关步骤不影响独立命题。

读报告、搜索和入库返回结果前检查来源账本、协议、工件和证明副本。变化使条目持久 INVALIDATED，并沿步骤引用传播；恢复文件不会自动恢复可信状态。主动 WITHDRAWN 同样传播。重新建立可信条目需新的来源审查和显式入库，不自动借其他来源替换失效证据。

每次读时复核当前状态；没有后台订阅或跨进程即时推送，已打开页面需刷新。该索引未接入证明生成器，不能宣称自动引理复用或求解率提升。猜想/固定目标任务的直接入库、一般 Lean 库打包、跨论文引理边及全局 SourceDocument 当前版本注册后置。

## 持久化与移除

`artifacts/knowledge/knowledge.sqlite3` 保存规范化正文、摘要、请求幂等和事件。单事务序列化入库；证明先写临时目录并核对，再提交条目。失败无可见条目，内容相符的孤立归档可在显式重试时复用，不能从归档恢复授权。数据库所有者与本机管理员仍受信，摘要不是持久签名。

“从知识库移除”先提交 DELETED 墓碑并清除该条目及依赖子树的公式/引文/复制元数据，再清除对应证明归档；保留最小来源标识、事件及不可用状态以防复活。原始审查账本不受此操作删除。中断后可重复移除清理残留归档；这是应用层逻辑删除，不承诺磁盘安全擦除、清除备份或原始审查。无公开共享与训练流水线。

## 验收

真实 Lean/E4 正例入库与归档、精确公式/全部前提、来源撤销/源工件/归档变化失效、步骤级联而命题独立、无自动复活、私有权限确认、事务失败/并发幂等、删除及路径边界，另验实际浏览器入库、图谱/列表、检索、撤销传播和手机布局。既有 Lean、受信模板、编译器和证据政策不变，无新增依赖。
