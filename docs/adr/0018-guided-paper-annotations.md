# ADR-018：单定理表单标注与无损公式转换

- 日期：2026-10-26
- 状态：采用；验收见 `docs/evaluation/annotation-editor-results.md`

## 问题与选项

单定理审查已具备真实验证，但用户必须编辑完整 JSON 与 Nat AST，操作门槛较高。比较继续只提供 JSON、引入公式编辑依赖、由模型自动抽取、在现有页面提供有界文本公式表单。选择最后一种：无需新增依赖或配置模型，允许用户明确标注原文及公式。自动抽取仍单独评测后接入。

## 决策

在现有 `papers.js` 增加表单与数据型公式解析，不执行输入代码。表单编辑原文标识/版本/标题、自然数变量、前提、结论、行号、至多四步及此前步骤引用；检查策略仍为已有四种受限计划，选择策略不意味着通过。原文行号随输入更新，错误不退回最后一份有效 JSON 提交。

中缀公式编译为现有 Nat AST，明确优先级、蕴含右结合、截断减法与显式乘号。无隐式乘法、负数、除法或幂。表单与 JSON 切换须逐字段无损；不能表示或含额外字段的 JSON 留在原编辑模式，不悄悄删除内容。移除步骤后保留后续引用并报错，要求用户自行调整。

上方文本草稿仅经明确点击带入，不推测变量/结论/步骤，不截断过长原文。新建表单的结论留空，不自动填入可证明命题。导出标注只下载 JSON，不启动检查。编辑使已准备计划与复选确认失效；真实运行仍需服务端准备、逐项核对及具名确认。

## 验证与边界

验证运算优先级、类型、AST 无损转换、输入预算与拒绝路径；实际浏览器覆盖表单/JSON、修改后重新确认、错误恢复、文本草稿、步骤引用与手机布局，再运行真实 Lean 及独立重放。

不修改 `paper_review.py`、Nat 编译器、证据门禁、运行快照和知识协议；已有审查/知识来源不因页面改动失效。不是自然语言自动形式化，不增加数学领域或模型能力。

## 回滚

恢复旧 `papers.js` 与共享样式即可退回 JSON 入口。无数据库迁移，不改历史审查或知识档案。
