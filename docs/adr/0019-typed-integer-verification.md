# ADR-019：显式整数域与跨领域验证入口

日期：2026-10-26。状态：采用，完成标准见整数验收报告。

## 问题与选择

长期目标是支持数学四大期刊级原创研究。当前自然数单定理平台缺少类型域的扩展能力；尤其自然数截断减法不能冒充整数减法。比较让模型生成自由Lean、复用整数域显式类型AST、先实现整套研究编排。先选择第二条，构建可验证的小步扩展，保留原限制与真实独立重放。

## 设计

整数使用独立 `int-formula-v1`、`int-bounded-search-v1` 与 `int-paper-review-v1`，独立数据侧文件和受信模板。允许有界负整数常量、整数取负和负反例取值；自然数旧协议继续拒绝这些输入，保留其截断减法。类型绑定进入命题、计划、证据、审核和知识来源指纹，不允许把同式自然数证明换标签当整数证明。

首期沿用omega/simp/decide/显式反例与既有预算，支持CLI/API/论文表单、双通道审查和知识归档。乘法可表达，不宣称可解决一般非线性整数问题。模型猜想生成暂保持自然数协议，数学范围由表单或结构化输入明确指定。

受信编译器、策略模板与政策变化须先保存旧封存，再实际校验固定Lean/Mathlib档案并重封存。旧审查源绑定完整实现SHA；本轮修改协议实现会使旧审查/知识停止对外提供结论，原始记录与工件继续保留。不得替用户自动接受新形式化；新版需重新准备并具名确认。知识索引只能使用当前仍满足来源协议的真实E4义务。

## 验证

必须覆盖负数/取负/整数减法、同式Nat与Int不同结论、负见证反例、真命题错误原证明、未知与失败区分、域与审核/证据不匹配拒绝、旧自然数回归、实际候选与独立重放。浏览器覆盖显式域切换、表单/JSON无损、反例输入、两种判决、手机布局和私有归档。

## 回滚

恢复备份的受信代码、政策、模板范围与原封存，服务重启。数据库不改旧记录；撤销/失效状态不自动复活。历史恢复应使用备份副本审计，不将回滚当新认证。
