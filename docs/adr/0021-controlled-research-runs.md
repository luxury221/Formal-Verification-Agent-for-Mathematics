# ADR-021：受控多节点执行

日期：2026-10-26。状态：已采纳并验收。

研究图管理与历史证据绑定保持原协议。新增独立 research-runs 账本，冻结分支图、原问题、定义语境、每项完整命题与受限检查计划、外部已证前置、实现摘要和运行快照；预览不运行模型或 Lean。最多选择八个节点，逐项确认后才可提交，同一分支最多一个活动执行。

执行持有既有继承式 worker 锁，按拓扑顺序调用原 PaperReviewStore.execute，复用真实 Lean、独立重放及证据门禁。每项检查独立完整命题，研究依赖和定义笔记不会被编译成假设。未选前置必须有当前有效的 PROVED 绑定，已选前置必须在本轮真实通过；否则后继跳过且数学判断为 UNKNOWN。执行不会自动绑定研究图。

总配额包含检查次数、预留的 worker 秒数和首次执行起的墙钟秒数。每项检查不可退还地预占一次和三十秒；候选与重放共用原三十秒。完整性扫描计入墙钟，但无法被即时抢占；超期停止当前检查和后续调度，禁止超期发布新结果。已完成结果可在额度耗尽后保留。

子审查使用确定性 ID，直接持久化为 RUNNING，从不进入通用 QUEUED 队列。原 execute 的完成状态由适配器暂缓，父执行在同一父事务保护下再次核对取消、图、前置、工件及截止时间后才发布。取消、图或来源失效撤销本轮所有子来源；原有外部证明不受影响。失效持久保存，恢复文件不会复活旧结果。

中断恢复必须取得原 worker 锁，将残留 RUNNING 执行记为 INTERRUPTED，撤销本轮子审查，保留已预占配额及工件。不从残留检查报告恢复数学结论，也不自动续跑；需重新预览、确认并提交新请求。SQLite、本机用户及单机运行边界仍受信；不提供跨库分布式事务、身份认证或不可变签名。

运行状态与每节点的数学判断分别显示。没有作者步骤，因此真实命题检查通过也不等同于验证了一份原作者证明。当前仅 Nat/Int 有界语法及既有策略；模型调用为零，不表示已具备四大期刊级原创求解能力。
