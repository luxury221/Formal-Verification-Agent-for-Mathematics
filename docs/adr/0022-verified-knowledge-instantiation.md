# ADR-022：来源绑定的知识实例化

日期：2026-10-26。状态：已采纳，首期已验收。

MRA030首期实现已验证私有引理的显式实例化，保留原验证核心及历史协议。新增独立 `knowledge_instances` 适配器和第七账本；以只读的单节点执行视图复用 ResearchRunStore、ControlledReview、worker锁、预算、取消、恢复与真实Lean/独立重放。实例不是额外研究项目，原研究账本不增加隐式项目。

只使用当前ACTIVE、完整PROVED/E4的知识条目。替换一个或多个连续的最外层forall变量，代入Nat/Int有界项；可引入最多四个具名新全称参数，必须与原公式全部量词名互异且实际使用，避免变量捕获。不替换存在量词，不删除蕴含前提，不增加假设，不跨数学域；结果仍由原受信语法检查完整范围及预算。

预览不调用Lean。保存不可变实例草稿仍为UNKNOWN；随后预览检查计划，具名确认原文、代入、完整公式、来源及预算，重新独立检查完整命题。引用关系和新的真实证据分别记录。首期没有导入归档证明项、一般引理战术调用或Mathlib新定义，也不把重新证明结果宣称为知识复用提高了解题率。

计划绑定来源条目版本/完整内容、来源与归档摘要、实例化实现及既有检查协议。来源撤销/移除/损坏使实例持久失效，撤销由本实例生成的审查来源；文件恢复不复活。只读、提交、运行前/中/发布前复核，后台逐项巡检；公共知识API/CLI读取前核对实例来源，以使已归档实例的引用也能失效。暂不以本模块生成的实例作为再次实例化的来源，避免未实现的跨实例递归依赖语义。

检查维持单次30秒候选与重放共享worker预算，并可设置1–600秒墙钟；中断不发布残留结果，需重新确认新请求。原research_runs/research/paper_review/knowledge与受信编译器不修改、不重封存。本机SQLite、宿主、具名声明与同一Lean内核实现的既有可信边界不变。Mathlib定义和一般证明引用留待独立版本实施。

浏览器并发验收暴露了全库写锁竞争：实例轮询若反复调用原知识库全量刷新，可能将临时SQLITE_BUSY误记为永久来源失效。实例适配器因此对引用及其依赖闭包执行只读核对，仍复用原verified_source、归档哈希、账本读取/事件/级联规则；核对后再次读取版本，真实损坏持久停用。临时BUSY/LOCKED向上报告不可用，不永久污染草稿；运行遇到存储故障保持失败/未知，不发布未审核结论。原知识库实现文件保持不变。
