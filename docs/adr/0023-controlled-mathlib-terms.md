# ADR-023：独立的受控 Mathlib 证明项实验

日期：2026-10-27。状态：已采用并完成本地首期验收，证据见 [mathlib-lab-results](../evaluation/mathlib-lab-results.md)。

既有 Nat/Int 协议没有整除定义或一般引理调用，知识实例化也没有导入证明项。直接改其编译器、封存政策或历史来源适配器会使原证明来源失效。本轮新增独立 `mathlib-nat-divisibility-v1`，不扩大旧签发协议，不改旧运行快照或冻结模块。

范围是现有 Lean 4.35.0 / Mathlib 56a005855ea17e0b0958f73ec801ae140b0a1679 内的自然数整除，九条明确引用，含三条 Mathlib 中的等价定理。结构化表达式保留所有全称变量、前提、类型及截断减法；证明项只允许白名单引用、显式 Nat/证明实参、已有假设、合取与等价应用。没有任意 Lean、自动搜索或模型调用。未知定义、缺失实参和超预算均拒绝；类型错误由真实 Lean 拒绝。

第八个本地账本保存具名确认、不可变计划、事件、工件摘要、取消与撤销。复用原隔离进程启动器及独立内核重放，另行核对完整目标及闭包公理；候选与重放共享最多30秒 worker预算。源码、目录、政策和原环境封存一起绑定每个计划；变更或工件损坏永久抑制历史结论。进程状态与数学判断分开，搜索/类型失败保持 UNKNOWN，只有真实双阶段与具名对齐均有效才记录 PROVED/E4。恢复标 INTERRUPTED，不从残留工件签发。

首轮实测发现默认导出器递归展开已导入库引理的证明依赖，使一个减法样例超过30秒。新增独立导出片段，只导出新增声明及其表达式，库常量的名字与实参保留；独立重放从同一封存基线解析库常量，仍核对新增证明、公理闭包及确切目标。没有增大预算、移除公理审计或更改旧导出器与封存。首轮超时及诊断日志保留，不能将后续通过覆盖旧记录。

共享现有 worker flock，子进程继承锁，串行执行；正式服务交付前恢复。实验结果目前独立导出，尚未接入旧研究图或知识入库，它们的算术域不能容纳整除式，禁止把实验伪装成旧算术义务。后续需要版本化跨域适配器及独立领域评测。

不引入新依赖或下载：复用已登记的 Apache-2.0 Lean/Mathlib/LeanExport 和 Python 标准库。功能样例由项目编写，不是原创性、自动研究能力或顶刊难题的证据。
