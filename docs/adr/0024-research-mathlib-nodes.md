# ADR-024：研究项目中的版本化 Mathlib 节点

日期：2026-10-27。状态：首期已验收。

原研究图只接受既有Nat/Int算术公式，直接修改其实现或封存会停用已有证据。MRA033采用独立扩展账本，按原project_id与branch_id挂载Mathlib整除节点，在同一研究界面显示。旧研究、Mathlib检查器及其封存不改；不把整除目标改写为旧算术式。

每条研究线最多16个扩展节点，保存完整原文、受控Mathlib请求、节点种类、显式依赖、笔记、图版本、绑定与事件。首期依赖只在本研究线扩展节点内成立；旧算术图独立显示，未实现混合调度。前置用于研究管理，不注入Lean假设，主问题仍需其自身确切完整证明。

预览与具名绑定只复核已有真实COMPLETED/PROVED/E4来源，不运行新Lean。严格匹配完整请求和原文，包括类型、所有前提、结论、证明实参及预算；前置未证明则阻塞。Mathlib检查、导出、重新带入与明确绑定分别记录，不因运行完成而自动绑定。

绑定固定当前项目问题与研究线语境、扩展节点内容、每条前置绑定指纹、来源计划/对齐/工件和适配器实现摘要。来源撤销/损坏、语境或节点变化、前置撤销都会永久停用绑定；恢复文件或重绑前置不自动恢复后继。原独立Mathlib证明保留。读取、公开来源撤销后的定向复核及空闲巡检负责持久传播；跨SQLite库没有全局原子事务，临时BUSY/LOCKED只报告不可用，不作为数学失效。

使用只读原项目账本核对行摘要，不在审计期间刷新全部旧来源，也不改动旧绑定。新增图与事件有界，具名操作、乐观版本、幂等、历史及精确导出均在本机私有范围。分支默认不继承扩展绑定。所有正向验收使用真实Lean及重放，不以模拟来源替代。模型继续稍后配置，无新增依赖、下载或训练。
