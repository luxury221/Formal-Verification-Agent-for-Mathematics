# ADR-025：Mathlib 私有成果归档与检索

日期：2026-10-27。状态：已实施并通过本地验收。

MRA034采用独立的 `private-mathlib-knowledge-v1` 适配器及账本，接入现有知识库页面与全局搜索。原知识、Mathlib检查、研究图及其封存实现保持不变；完整Mathlib命题不会被改写到原算术协议。

只收录当前可用的真实COMPLETED/PROVED/E4 Mathlib实验。复用冻结研究桥接器的确切来源审计，固定完整原文、请求、证明项、语义确认、公理、版本、候选与独立重放结果及文件哈希；具名确认完整条目和本机私有保存权限后复制证明工件。归档不产生新Lean认证，不导入证明项作为后续目标的可信引理。

一个运行对应一个稳定条目ID。精确公式结构指纹提示重复命题，但不猜测alpha等价或合并不同来源。归档副本、源确认或来源工件变化、适配器变化会使条目持久失效；恢复文件不复活，撤销/移除也不自动重新入库。研究图的管理依赖不成为归档逻辑依赖，研究绑定的撤销不影响原独立Mathlib证明。

每次读取复核源和副本，HTTP撤销源后定向复核，空闲worker每10秒轮巡一个归档。跨SQLite无全局原子事务；源审计与文件复制在侧库写锁外完成，提交时进行乐观比较。BUSY/LOCKED只报告暂不可用，不污染结论。部分文件复制失败无可见ACTIVE条目；原子目录重命名后数据库提交失败的孤立副本可在完全一致时重试。

条目最多500、请求最多2000、每条128个源文件、单文件16MiB、总源文件64MiB，拒绝符号链接/目录逃逸。移除会清除本条目副本和内容，只留最小标识与操作审计；原实验独立保留。没有派生证明依赖此归档；带回操作仅恢复完整请求，重新预览确认与真实双阶段检查后形成独立新实验。

界面提供完整来源预览、入库/重复提示、关键词检索/失效筛选、证明清单、撤销/移除、导出和带回。来源/私有状态显示明确，编辑清确认、异步响应防串页，桌面和390px验收。模型仍稍后配置；无新依赖、下载、共享或训练。

验收：71项受影响主回归全部通过；视觉修正后29项重复界面/协议回归通过。实际Edge14项、9截图与10条实际CLI验收；源与归档及旧账本保留核对见 `artifacts/mathlib-knowledge-delivery-check.json`。这不是全历史回归，也不是模型或原创问题求解评测。
