# ADR-026：私有 Mathlib 引理的显式实例化

日期：2026-10-27。状态：已实施，受限范围通过本地验收。

MRA035使用独立 `private-mathlib-reuse-v1` 适配器及账本。对当前可用的真实Mathlib私有归档，显式指定新的Nat变量和每个原全称变量的替换项，完整替换所有前提、目标及原结构化证明输入；由冻结编译器生成完整新命题。替换同时执行一次，不递归替换新插入项；保留前提顺序和名称，名称冲突或缺定义直接拒绝。

来源、替换前后原文与公式、完整证明输入和预算经具名确认后保存待检查记录，数学判断仍UNKNOWN/E0。带回Mathlib实验必须另行预览、具名确认并运行真实候选与独立重放；仅完整请求完全一致且当前真实COMPLETED/PROVED/E4的结果能具名关联。没有归档输出证明项导入、假设删除、自动搜索或自动晋升。

来源及结果均按现有冻结来源适配器核验。归档撤销/移除、工件或适配器变化、结果来源损坏或撤销，使引用链持久失效；恢复文件不复活。原独立Mathlib实验保留其自身判断。源归档移除不代表删除其他已明确创建的实例或实验；实例单独可撤销/移除，原实验独立保留。

源码、原知识和原验证账本不迁移。新账本最多400条、2000幂等请求，每条64事件/2MiB；替换输入64KiB、新Nat变量最多6、替换表达式深度8/合计80节点，新命题仍受原240节点/14深度/6前提/30秒共享worker预算限制。持久写入前在写锁外核验，乐观比较防覆盖；SQLite BUSY/LOCKED只暂不可用。读取复核，HTTP源撤销/移除后定向复核，空闲worker每10秒巡检一条。跨库非原子，宿主和文件系统仍受信。

界面在私有归档详情新增“实例化引用”，展示映射与完整前后公式；独立实例记录列表、带回、选择已有检查、关联、历史/导出、撤销/移除及390px布局。手动输入范围仅Nat整除现有定义，模型仍稍后配置，无新依赖/下载/训练。
