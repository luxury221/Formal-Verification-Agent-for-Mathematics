# ADR-027：包含失败与未知的 Mathlib 固定预算功能评测

日期：2026-10-27。状态：已实施并完成本地受限验收（MRA036）。

目前的 Mathlib 示例、研究节点和引理实例化已能保存真实证明，但成功示例数量不能衡量整体能力。增加独立、固定输入与预算的功能评测，将错误证明、缺失前提和未开放定义纳入同一分母，提供可审计的实际结果。

采用项目自编的8道结构化输入题，开发组2题、回归组6题，按题目族隔离且全部已被作者查看。冻结完整原文、变量、前提、目标、证明输入、编译器/环境/策略和评测适配器摘要；具名确认计划后经CLI执行。每题至多一次候选检查和一次独立重放，共享原30秒worker预算；不自动修复、重试或跳过失败。环境完整性扫描另计时，不将worker预算描述为整轮墙钟时限。

每轮在 `artifacts/mathlib-evaluations/ml-bench-…/` 保存冻结计划、报告、租约及独立校验库，复用原 MathlibLabStore 执行、独立重放及全局worker锁。原生产账本、验证器、研究图、归档/实例适配器和运行封存均保持原协议。没有新增生产SQLite账本；每轮含一个独立的校验数据库。

运行状态与数学判断分开。Lean拒绝证明、超时、策略阻塞和不支持的定义均保持UNKNOWN，不能标为REFUTED。未开放定义保留原文和输入，不改写问题，不启动Lean。逐题真实工件仍由原检查器审计；损坏、来源变化、残缺、整轮中断时隐藏整轮通过率。已失效的子检查在恢复文件后不复活。

通过率仅命名为作者输入检查通过率；模型求解率与自然语言对齐准确率始终为空，模型调用0。题目不是持出盲测，不能据本轮比例声称求解收益或原创研究能力提高。后续真实模型接入或独立持出对照需单独协议和验收。

前端 `/evaluations` 新增题目/完整输入、预算/命令、历史、逐题报告与JSON导出，保留原模型策略评测区。HTTP仅计划/列表/详情读取，不执行评测。无新依赖、下载或训练。

实际结果为8题全部处理、3题真实PROVED/E4、3题证明拒绝、2题定义阻塞；后5题保持UNKNOWN/E0。73项相关主回归、28项重复界面回归、实际Edge11项流程/10张截图及8条CLI成功或预期拒绝通过；详见[验收](../evaluation/mathlib-evaluation-results.md)。
