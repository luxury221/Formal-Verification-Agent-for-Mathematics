# ADR031：有限反例实验与原猜想否定的真实核验

日期：2026-10-27。阶段：MRA040。

MRA039 的 4 个未知目标同时包含错误猜想和策略缺口。仅扩充正向搜索不能区分两者，因此按蓝图的反例与证据分层原则，增加独立的有限 Nat 反例流程。保留 MRA038 搜索器、MRA039 数据和原始分数；新结果不回填旧评测。

实验输入是原数论语言中没有证明项的完整目标，最多六个 Nat 变量和六个前提。枚举每变量 0 到指定上界，默认上界 4，最大 32；最多 5000 组赋值、100000 次语法树求值、256 位中间整数和 0.5 秒协作式实验时间。满足全部前提而结论为假的赋值只是 UNKNOWN/E0 候选。未命中、溢出、预算耗尽和有限域穷尽都不证明原猜想。

候选导出后先准备完整核验计划。新适配器沿用冻结数论编译器验证目标，生成原命题的完整否定；将每个全称 Nat 变量实例化为确切数值，以宿主固定的 `by decide` 证明各个封闭前提及结论的否定。输入不能传入 Lean 源码、任意战术、额外前提或证明项，不使用 native_decide 或 Lean.ofReduceBool。

明确审查原文、全部条件、数值、原式和否定方向后，具名确认精确计划指纹。子检查器继承冻结 MathlibLabStore 的候选执行、目标类型审计、公理政策和独立证明数据重放，只改变计划编译、扩展 manifest 与每次存储位置。子检查 PROVED 的对象是**否定命题**；只有父流程完成、子证据 E4 且完整性通过时，原猜想才显示 REFUTED/E4。两层命题和方向同时保留，避免把否定的证明错误显示为原命题已证明。

每次最多一个候选进程和一个独立重放，共享 1–30 秒 worker；环境扫描另计。沿用全局 worker 锁、独立 lease 和原子 JSON envelope。相同确认重复执行只读，不同核对者拒绝接管。进程中断不从已完成子证据补出父结论；检测漂移持久停用，恢复文件不复活。单次记录存放在 `artifacts/nat-counterexamples/cex-<32hex>/checks/`，不新增主业务库，不自动写入知识库、研究图或旧评测。

HTTP 只开放有限实验 POST，以及计划/历史 GET；不开放 Web 准备或执行核验接口。浏览器提供实验、完整候选导出、CLI 核验步骤和历史报告，准备及真实检查由本地 CLI 执行。姓名为本地语义对齐声明，不是身份认证或专家背书。

没有新增依赖、模型调用、外部数据、Euler 实现或运行重新封存。适用范围仍为受限 Nat/gcd/互素语言和小数值反例；不等价于一般数学反证搜索。验收见[结果记录](../evaluation/counterexample-results.md)，操作见[协议](../protocols/counterexamples-v1.md)。
