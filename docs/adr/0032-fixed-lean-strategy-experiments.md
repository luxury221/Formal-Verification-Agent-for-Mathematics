# ADR032：完整 Nat 目标的固定 Lean 策略实验

日期：2026-10-27。阶段：MRA041。

MRA039 的可见功能题中，旧有界引用搜索无法证明 `a≤a`。MRA040 的有限枚举也不能由“没有反例”推出其成立。因此增加独立策略入口，让同一完整目标进入真实 Lean 战术，保留旧搜索器、旧评测与原分数。

选择两个宿主固定策略：`omega` 处理自然数线性算术，`simp-gcd` 使用列明的六条 gcd、互素与整除规则做 `simp_all only` 化简。复用冻结的 Nat/gcd/互素编译器，输入不含证明项、任意 Lean 战术、导入或额外假设。编译后仅替换证明来源，完整量词、原前提和结论不变。

这是一条完整目标的一次战术尝试，不是一般证明状态交互或回溯搜索 API。保留全部假设不等于证明其相容；不相容前提可能使蕴含命题空真，预览和结果必须保留这个限制。自然语言原意仍需本地具名审查，姓名不等于认证。

每次预览均保持 UNKNOWN/E0，不运行 Lean；核对原文、Nat 域、变量、前提、结论、固定策略和预算后，以确切计划指纹具名确认提交。一个候选进程加一个独立证明数据重放，共享 1–30 秒 worker、200000 heartbeats，没有自动重试。环境完整性检查另计。只有原执行器的类型审计、公理政策、独立重放和工件完整性均通过才 PROVED/E4；失败、超时、中断、取消和撤销保持 UNKNOWN。

继承冻结 MathlibLabStore 的执行、全局 worker 锁、审计、重放、取消、撤销和恢复行为；适配器与策略目录另有版本 manifest。记录独立存入 `artifacts/lean-strategies/lab.sqlite3`，成为第十四个主业务账本；不迁移原十三库，不自动写入研究图、知识库或旧评测。后续备份必须发现全部十四库，同时保留每次运行目录，不能继续使用固定十三库的旧辅助脚本。

浏览器 `/strategies` 提供完整编辑、两种策略、六份作者可见示例、预览确认、真实提交、反馈、历史、取消、撤销、带回及导出。编辑、示例或预算变化都使旧计划失效，过期预览响应被丢弃。CLI 提供同等的 catalog/preview/submit/work/report/list/cancel/revoke/recover 操作。

没有新增依赖、模型调用、外部数据、Euler 代码或运行重新封存。沿用 Lean 4.35.0、固定 Mathlib 和既有内核；独立进程仍使用同一内核实现，并非第二种证明器。作者可见功能样例不构成独立持出成绩、模型能力或四大期刊级原创研究证据。见[协议](../protocols/lean-strategies-v1.md)与[结果](../evaluation/lean-strategies-results.md)。
