# ADR035：将完整推演证明具名关联到研究节点

日期：2026-10-27。阶段：MRA044。

受控推演已经可以获得完整 E4，但研究页缺少明确的来源关联。采用独立 evidence 视图，在原任务旁保存具名关联，保全冻结的路线执行协议及其历史结论。关联本身不执行 Lean；读取既有候选类型/公理审计、语义确认、独立证明数据重放与文件摘要。预览 UNKNOWN/E0，确认完整命题后，有效关联视图可显示 PROVED/E4，fresh_attestation=false。

关联必须来自同一 flow、同一 node、同一完整目标、同一计划指纹与原前置绑定。只接受 accepted、COMPLETED、CLOSED、无取消/失效/错误的推演及真实 PROVED/E4 子检查。完整原问题需要自己的证明，不能由若干已关联引理推断出来。核对者姓名是本机审计记录，并非身份认证。

账本保存在 artifacts/research-evidence/flow-*/record.json，不增加主库。摘要信封、原子替换和 fsync 沿用既有实现；基目录短锁保护发布，单 flow 锁保护修订与幂等请求。最多50个 flow，每 flow 128关联、每节点16关联、512请求；单信封上限2MiB。计划绑定程序摘要、来源完整快照和账本修订号。撤销不删除原证明；来源、计划、程序或账本漂移持久失效，恢复文件不复活。短暂锁定返回可重试错误，不持久失效；重试必须由用户明确发起。

关联不满足冻结原路线的前置调度门禁，不导入 Lean 假设、不自动入库、不计为新重放。界面并列展示“关联依据”与“原路线结论”。后续跨路线调度应通过有明确版本与撤销规则的新协议实现，不能悄悄改写旧执行记录。

无新增依赖、模型、外部实现或数据。模型继续未配置；作者可见的小例子验证工程机制，不代表重大原创数学求解能力。见[协议](../protocols/research-evidence-v1.md)和[验收](../evaluation/research-evidence-results.md)。
