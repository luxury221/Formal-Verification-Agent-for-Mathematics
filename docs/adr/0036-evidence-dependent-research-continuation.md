# ADR036：使用已审计前置证据继续检查后继命题

日期：2026-10-27。阶段：MRA045。

MRA044 的来源关联不能解除冻结路线的门禁。本轮增加独立依赖续研协议，复制既有任务的完整不可变图及原计划指纹，在新账本中消费原路线、具名推演关联和续研独立结果。原路线与关联协议、检查器、公理策略和重放实现保持冻结。继承原执行、取消和具名撤销机制，新增上下文/依赖审计、计划确认及恢复隔离。

只有当前 PROVED/E4 才满足研究前置；REFUTED、冲突、未知或失效均阻塞。按拓扑顺序选取来源，固定优先级为原路线、最早有效推演关联、最早有效续研尝试。每个来源有具体标识与指纹。加入未使用的同类备选不改变所选来源；撤销或替换所选来源会永久停用依赖它的历史尝试，即使另一证明仍可满足门禁，也必须重新准备、确认和检查。已完成子检查的独立证明工件保留。

每个后继命题单独执行完整原目标的真实候选审计和独立数据重放。研究依赖控制顺序，不注入假设，不导入前置证明项。本轮是调度闭环，不宣称通过引理复用提高求解能力。原问题没有自己的完整 E4 时始终未知；前置证明本身不自动证明原问题。

续研计划保存在 artifacts/research-continuations/flow-*，不增加主库。最多50个任务、24份提案、16次尝试；每次候选与重放共享1–30秒worker，最大480秒，完整性扫描另计。每任务单活动尝试，复用全局worker锁。发布与扫描共享基目录短锁，记录采用摘要信封、原子替换和fsync。来源/计划/程序/父语境漂移持久失效；忙碌是暂时错误。取消与中断不自动重试；原始重放成功但监督未提交终态，也不能补发已证判断。损坏记录或孤儿子库隔离。

浏览器验收暴露了继承报告函数的边界问题：嵌套来源审计的 WorkerBusy 被当作 RuntimeError 写入永久损坏标记。续研模块改为独立报告入口，先传播 WorkerBusy 与 SQLite 暂时错误；冻结原模块不修改。回归同时核对记录字节、损坏标记不存在，以及锁释放后的后继仍为 PROVED。受影响记录保留失效历史，不删除标记或复活尝试；修正后用新记录重新执行真实实验。

网页在 /research 下提供独立续研区，逐项准备并具名确认，可查看完整依赖来源、取消、撤销与导出。活跃详情在上一读取结束后5秒读取，不轮询全历史；初始暂时失败可手动重读。来源变化或语境切换清除确认，丢弃迟到响应。姓名是本机审计标签，不是身份认证。

无新增依赖、模型、数据、Euler代码、训练或重新封存。模型继续未配置。见[协议](../protocols/research-continuation-v1.md)和[验收](../evaluation/research-continuation-results.md)。
