# ADR039：私有引理组合工作台

日期：2026-10-28。状态：采用，验收结果单独记录。

MRA047 已提供真实检查的私有证明数据组合核心，但网页与后台 worker 尚不消费该账本。本轮增加 `/compositions`、`/v1/lemma-compositions` 和现有单 worker 的组合调度；保持原数学协议、导入模板、独立重放及公理政策不变。

网页使用来源卡片、Nat 公式表单和有界结构化证明树。来源详情仅返回受校验的完整签名、版本、出处与对齐元数据，不返回原 Lean 源、原证明输入或 NDJSON。复用完整原条件，目标预览展开每次同时代入及全部前提证明。具名确认必须绑定核心生成的完整计划指纹；任何输入、来源或姓名变化清除旧确认。迟到响应不能恢复旧计划。

页面请求串行处理。只读 GET 遇到 503 最多重试两次，之后提供手动恢复。POST 一次点击只发送一次；不确定提交可人工用原 ID、原正文重提，编辑后必须新 ID。HTTP 沿用同源、CSRF、严格 JSON、192KiB 上限和固定资源路由。历史读取与导出都重新调用核心门禁；暂忙不当作永久损坏。

组合调度追加到既有单 worker，继续共享全局生命周期锁。HTTP 线程不执行 Lean。取消、撤销、工件失效和中断语义由原账本处理；运行状态与数学判断独立显示，历史结果明确 `fresh_attestation=false`。

本轮不增加自动证明搜索、模型调用、新数学语言或研究图关联。姓名只是本地声明，前提相容性与自然语言忠实性仍需另行审核。同一 Lean 内核的两个进程不构成两种独立实现。

验证要求：实际 HTTP 安全及严格输入、预览无执行、幂等与失效、真实后台两阶段与错误前提保持未知；实际 Edge 桌面与390px流程、编辑/迟到响应门禁、单发提交与手动同ID恢复、取消/撤销/导出；源代码自review、旧库逐行保全和旧证据摘要复核。
