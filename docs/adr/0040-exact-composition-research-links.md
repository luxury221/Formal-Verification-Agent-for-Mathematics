# ADR040：组合证明到研究图的精确具名关联

日期：2026-10-28。状态：采用；验收记录独立保存。

现有原路线、推演关联和续研实现都绑定各自的源码版本，直接增加新来源类型会使旧证据失效。本轮在 `artifacts/research-compositions/` 新建独立有界文件账本；既有数学协议、组合内核、原路线、推演及续研实现保持原摘要。

新视图读取原路线/推演/已存在续研的实际有效来源，并可具名关联完整组合E4。严格匹配原文、标题、变量名和顺序、全部原前提、完整结论、域与预算，仅将组合协议的schema字段映射到相同Nat目标协议；形式化完整类型也必须一致。没有弱化前提、自动alpha等价或依赖注入。

关联计划绑定flow/node、完整任务计划、父研究语境、当前具体前置证据指纹、组合计划、原具名对齐、真实候选与独立重放、工件摘要及桥接实现版本。预览UNKNOWN/E0，不执行Lean。提交需要新具名确认/计划指纹/稳定请求ID；重复提交返回原历史，不能复活已撤销或失效关联。

按拓扑顺序复核：只有前置节点当前PROVED才允许关联后继；撤销或替换已选择的具体前置、组合确认撤销、私有源撤销/改变、工件漂移、原研究语境变化都会持久停用受影响关联，并传播到依赖后继。恢复字节或重放旧请求不恢复旧确认。添加未被选用的替代来源不改变既有后继的依赖指纹。相反数学结论相遇时保留UNKNOWN。原问题必须有自己的完整证明，不从引理数量推定成立。

新视图不改原路线/续研历史，不自动为旧调度器解锁，也不运行新检查。它直接把已证组合用于研究证据图；后续可用新调度协议执行更复杂的图，不能为保持旧协议兼容而夸大当前能力。

来源候选目录只筛选完整目标相同的历史标签，明确标为待预览复核；预览、关联、读取、导出均核对真实来源。WorkerBusy及SQLite锁忙作为临时错误传播，不持久记作损坏。文件原子发布、非阻塞有序锁、严格JSON、有限请求/历史和损坏标记沿用既有工具。姓名仍为本地声明，历史不是新认证。

网页在 `/research` 增加组合证据面板，复用统一串行请求协调；支持把完整目标带入 `/compositions`、预览来源及具体前置、具名关联、撤销、完整导出和390px布局。编辑、源变化和切换节点清旧确认，迟到响应不得改写当前节点。HTTP/CLI均提供report/catalog/preview/bind/withdraw/export对应能力，不增加模型/下载/依赖。
