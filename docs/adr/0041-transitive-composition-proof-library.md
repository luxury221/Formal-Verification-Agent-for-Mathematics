# ADR041：组合成果的授权归档与传递来源

日期：2026-10-28。状态：采用，真实验收证据独立保存。

原Mathlib归档适配器只接受其原协议，组合结果使用更广的受控Nat目标（含gcd/互素/合取等），不能通过改标签写入旧库。原组合、归档、研究桥接和Lean导入/重放实现均被历史证据绑定；本阶段保持其文件摘要，新增明确版本的证明库和组合执行器。

`artifacts/proof-library/library.sqlite3`是一个新增主库，items/requests保存授权私有归档，runs保存新版本组合。原组合和新库组合通过显式origin区分，不从随机ID推定协议。归档预览保留完整原目标/所有前提、原具名对齐、候选和独立重放审计、工件摘要及传递来源；重新具名确认存储权利后私有复制，不新增Lean运行，不授权共享/训练。未知、失败、撤销、损坏、未对齐或无独立重放的记录不得入库。撤回/移除和旧请求保持原子、幂等与持久停用。

新组合可同时引用旧Mathlib私有来源和新组合归档。使用原Nat证明项编译器和数据导入模板；每次提供全部量化实参与原前提的证明。归档NDJSON只作为数据被内核检查，不执行归档Lean代码。新完整目标仍需候选审计及独立进程重放，两进程共用原worker预算。新执行器的检查流程由冻结MRA047执行流程生成静态源码后逐项review；运行时不修改原模块或替换其全局函数，生命周期/取消/中断逻辑沿用单worker锁。

直接来源和传递祖先绑定具体item/version/内容指纹，目标类型与声明保持完整。最多4直接来源、64归档祖先（包括新条目自身）、8层归档深度和512KiB单份证明数据。每次审计限制128次遍历，暂忙/预算耗尽传播临时错误，不能误写健康来源为永久损坏；检测循环则拒绝。来源撤销、变更、删除、原语义对齐撤销或工件损坏沿传递依赖持续停用，恢复字节/旧请求不能复活；重新具名执行可形成新的有效结果。

本阶段验证至少三层真实链式复用，以及条件不足/错误证明、跨版本来源、源撤回/损坏恢复、取消/中断、忙锁和权限确认。既有记录与工件逐行/逐字节保全。姓名仍为本地声明，历史不是新认证，两个进程仍用同一Lean内核实现。该阶段提供可累积的证明复用，不代表自主发现、新颖性或重大难题能力；研究图消费新协议和独立同预算收益需要后续专门实现与评测。

新账本检测摘要或身份损坏后写独立持久停用标记，恢复旧账本行不会恢复旧证据。标记与库/原来源/私有工件一并备份；本地文件仍受宿主用户控制，不提供恶意宿主防回滚能力。网页撤回/移除的请求身份同时绑定具体条目和操作类型，避免相同姓名/原因跨操作碰撞；同一操作失败后的人工重提继续使用相同正文及ID。

已执行11项归档契约、2项真实Lean综合集成、相关127项回归（93通过/34旧真实跳过）、27条实际CLI及Edge完整和定向流程。监督进程在真实重放成功但提交前退出仍保持UNKNOWN；隔离实验上游撤回后全部后继停用，主库有效演示链保留。失败账目、最终界面复验与保全数量见[验收](../evaluation/proof-library-results.md)和 `artifacts/proof-library-20261028-01/`，协议见[proof-library-v1](../protocols/proof-library-v1.md)。
