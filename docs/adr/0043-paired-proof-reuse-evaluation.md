# ADR 043：完整目标的证明复用配对机制评测

日期：2026-10-28。状态：接受，实施前登记。

现有研究批次展示了可复用的真实证明，但正例不能说明复用是否节省资源。模型尚未配置，作者已看过输入和证明；本实验不报告模型解题率、独立盲测成绩或原创研究能力。

固定五个作者自有诊断输入，比较同一完整目标的两种程序：导入前置真实证明数据（import），或把同一前置程序按全部变量和前提实参同时展开（inline）。两组共享 Mathlib 引用、完整目标、源程序、30 秒单次检查上限和每题最多 2 次检查／60 秒 worker 总上限。inline 只有一个固定候选，不给额外生成或重试机会；未用预算不转题。候选和独立进程重放共享一次检查的 30 秒。

import 的冷启动成本包括前置证明构建及其重放；单独列出目标检查成本，不把预建成本当作零。来源不可用时 import 阻塞，inline 仍可从已公开程序和基础引用检查。结构超限只标记 UNKNOWN，不修改题目或放宽编译器。错误前提的程序必须交真实 Lean 拒绝。五题全部进入分母，成功与运行结束分开。

采用冻结检查器的新隔离存储适配器，不改既有数学协议、模板、归档或研究批次。预审无 Lean；具名确认绑定完整数据、程序、预算和实现摘要。运行后只审计已保存证据，不重新运行或自动补齐中断。工件损坏、撤销或实现变化使整轮统计持久停用；恢复原字节不能复活。局部历史仅用于诊断。

单轮、固定顺序交替目标变体，无重复统计或显著性推断；时间会受文件缓存、完整性扫描和宿主负载影响。详情见 `docs/protocols/proof-reuse-evaluation-v1.md`。
