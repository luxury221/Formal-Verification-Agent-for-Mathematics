# ADR 045：闭合的显式类型与非递归定义

日期：2026-10-28。阶段：MRA054。

研究图的既有公式主要属于 Nat，definition 节点只有文字语境。这不能表达实际可核验的函数与命题定义，也不足以承担路线 R1 的有理数接口。修改旧编译器或研究账本会使旧证据的版本依赖漂移，因此新增 `typed-definitions-v1`、独立账本和 CLI；旧研究图消费与知识归档另作后续接口，不声称已经自动接通。

先检查固定安装中的 Lean 4.35.0 核心 Rat 源码及 `.olean`，再用隔离真实探针核验 Int 局部函数、Rat 平方和分数等式。初次 `decide` 分数探针失败，日志保留；改用核心 `grind` 后候选检查和独立证明数据重放均通过。沿用固定的 `Mathlib.Data.Nat.Basic` 导入，无下载、额外导入或重新封存。

新语言显式区分 Nat、Int、Rat。所有字面量与参数有类型；仅允许显式向上转换。定义参数只访问本参数表与此前定义，不能捕获全局变量、前向引用或递归。函数结果为三种数值类型之一或 Prop，应用必须列出全部实参。量词有独立绑定和宿主生成名字，不允许同一作用域遮蔽。

定义编译为完整目标内的闭合 Lean `let`，包含明确函数类型与 lambda 参数。重放器在读入候选数据前即可从宿主生成的目标重建同一定义环境，避免依赖候选新增声明才能解释目标。原始定义、原文、变量顺序、全部前提、策略和预算都进入确认指纹；即使某项定义未使用也保留于计划，不只存展开后的公式。

只开放固定 `rfl`、`omega`、`grind`。复用原 `MathlibLabStore.execute`、运行环境完整核对、候选导出、独立进程数据重放、精确类型与公理门禁及最终事务。没有新增数学执行器或放宽 `sorryAx`／`Lean.ofReduceBool` 政策。候选与重放共享至多30秒 worker 预算；完整性开销另计，失败保持 UNKNOWN。

需要公开的语义边界：Nat 减法截断，Int／Rat 不截断；Lean 的 Rat 除法是总函数，`a/0=0`。分数字面量拒绝零或负分母，但一般除法允许零分母并明确其总函数含义；非零条件须由原任务提供。不能因语义习惯自动添加前提。前提一致性没有另行证明；条件命题成立并不证明条件可满足。

新增账本最多200次，使用同一全局 worker 锁，CLI 显式同步执行，不进入旧 HTTP 后台队列。沿用具名确认、幂等、取消、撤销、工件变化持久停用和中断后不晋升。后续若增加网页／研究图，必须显式展示完整定义及原条件，并按新协议核验；不能将旧 Nat 证明或文字 definition 自动视作新目标证据。

依赖仍是固定 Lean 4.35.0、Mathlib `56a005855ea17e0b0958f73ec801ae140b0a1679`（均 Apache-2.0）及既有 Python 标准库。作者示例验证接口，不代表真实模型效果、一般数学自动化或原创研究能力。实际验收与失败记录见 [typed-definitions-results.md](../evaluation/typed-definitions-results.md)。
