# ADR 046：完整类型定义环境进入项目研究

日期：2026-10-28。阶段：MRA055。

既有研究图针对 Nat 目标，文字 definition 节点不能承担 MRA054 的闭合定义语义。新增 `typed-project-research-v1` 文件账本与每图私有检查库，在同一研究项目／研究线下保存完整类型任务。保留旧图与检查协议；没有自动迁移或通过旧标签授予新证据。

图保存全部共享定义与每节点的原文、变量、原前提、目标、固定策略和预算。每节点生成独立 `typed-definitions-v1` 完整计划；即使定义未使用，也进入指纹。候选检查与独立重放复用既有执行器、环境完整扫描、精确类型和公理门禁；未改冻结验证器、模板或封存内容。

本期前置关系只决定执行资格，并将确认绑定到具体前置检查证据。它既不自动增加数学前提，也不导入前置证明项。原问题必须自行通过完整目标检查，不能从“前置引理全部已证”推断原问题已证。此项是类型任务编排，尚不主张证明复用收益。

逐次具名确认绑定图、完整节点计划、前置身份和预算。每图最多8节点／16次检查／480秒预留 worker 时间，单次候选与重放共用1–30秒；完整性扫描及锁等待另计。只有已确认节点进入原单worker，不自动遍历整图或重试。文件记录锁串行更新，全局worker锁隔离真实执行；只有持有全局锁才能恢复RUNNING。空闲恢复仅降级中断／取消孤儿，不重复完整审计或重写不变父记录；完整数学审计仍在报告读取、提交及执行门禁进行。worker提交检查结果时保留全局执行锁，并仅对父记录锁的获取等待至多30秒；不重试Lean或已执行的变更，正常读报告不再使已完成子检查误标中断。父任务启动、子任务尚QUEUED时中断，会同时取消该子项，避免无效排队。无法关联父记录的子队列也不自动执行。

工件、定义实现、项目语境、前置身份变化，以及具名撤销，会持续停用相关证据和后继确认。恢复原字节或重新证明前置不会复活旧后继。损坏图隔离；SQLite暂忙仍传播为暂忙，不作为永久损坏。文件与SQLite不具备跨介质事务；中断留下的子项由持锁恢复隔离，不通过猜测恢复接受。

独立网页 `/typed-research` 展示所有定义与原前提、完整Lean目标、分开的调度／执行状态和数学判断、候选及独立重放PID、语义声明和工件记录。结构化JSON编辑器明确其输入范围。迟到预览丢弃；编辑、切节点或姓名变化清确认；GET暂忙有限恢复；POST单发，传输失败保留同一正文与请求ID供人工重发。刷新／导出只审计历史，不重新执行Lean；读失败隐藏过期判断。

无新运行依赖。姓名仍为本地声明，独立进程使用同一Lean内核实现，宿主及本地账本受信。没有模型、一般集合／抽象结构／归纳、任意Lean、身份认证或四大期刊级研究能力证据。下一步应先设计完整typed证明数据复用及撤销传播，再开展领域评测。
