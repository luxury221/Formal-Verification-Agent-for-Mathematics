# ADR 047：类型化研究节点的实际证明数据复用

日期：2026-10-28。阶段：MRA056。

MRA055 的前置只控制调度，无法承担引理证明项复用。增加独立 typed-proof-composition-v1 协议、TypedReuseStore 与 CLI；目标只能来自保存的同一 typed 图，禁止在复用请求中修改原目标、条件或定义。每个直接前置必须选择一份当前 E4 来源，来源可以是原节点 node. 或同图同节点的新协议 run. 结果。

不改 typed_research.py 及其数学清单，以保留 MRA055 已确认目标与工件。新组合证据和原图数学判断分开，新协议完成原问题也不会把原 v1 图晋升。多级复用明确选择 run.；原 v1 的后继 UNKNOWN 不阻止当前有效的新协议来源。

完整共享定义要求逐字相等；显式实参严格匹配 Nat/Int/Rat，每条原前提都要对应证明项。实例化同时替换自由参数并 alpha-rename 量词绑定，避免源变量与目标变量同名造成捕获。定义在期望类型与实际证明项内均闭合为 let；不以任意 Lean 或自动 tactic 后备替代证明复用。

直接复用冻结 LibraryCompositionStore.execute；不复制候选执行、导入审计、完整性检查、公理政策或独立重放。现有导入器在读取数据前解释宿主完整类型，逐声明内核检查并隔离命名空间，已经支持闭合 let 类型。新适配器只提供完整 typed 签名、有界证明数据和具体活来源。

每次预览与门禁核对图语境、来源身份、工件摘要与传递祖先。撤销、损坏或来源替换在审计时持续停用后继，还原旧字节或重证不复活。具名确认、幂等、取消、监督恢复及全局 worker 锁沿用原语。最终提交事务递归审计本库祖先时共用当前 SQLite 连接，防止自身写锁死锁；不允许只读事务升级。实际执行时持全局worker锁，沿用图worker_audited只对记录锁入口等待至多30秒；不重跑Lean或已执行变更，普通报告读取仍传播暂忙。

最多200组合记录；每次1–30秒供候选与独立重放共享，无自动重试。新组合账本的预算独立于原图16次/480秒额度，二者不能混称共享总预算。最多4直接源、240证明节点/14层、320累计表达式节点、192KiB请求、8层/64祖先/128审计访问、每来源512KiB证明数据。完整性与等待另计，不作硬实时承诺。

先验收 CLI 与真实内核闭环，后续再接入现有页面和后台队列。没有新依赖、模型调用、一般集合/结构/归纳或独立数学研究能力证据。同一内核实现、受信宿主与本地姓名的边界保持。
