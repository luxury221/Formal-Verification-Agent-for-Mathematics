# ADR 048：类型化证明复用接入现有工作台

日期：2026-10-28。阶段：MRA057。

将 MRA056 的 typed-proof-composition-v1 接到现有 `/typed-research` 页面，作为当前节点下方的证明复用面板。新增 HTTP 适配器和共享传输，不创建新标签页，也不修改数学核心、来源清单、导入模板或独立重放。运行使用现有单后台 worker 和全局执行锁。

页面区分原图固定策略判断和新组合判断。来源目录只是候选；单独读取来源时才核对完整 E4，展示全部变量、原条件、定义、完整类型和语义确认。预览列出显式实参与每项条件证明；提交仍绑定原完整计划及具名确认。完成新组合不晋升原图，撤销组合与撤销原节点是两个入口。

原图和新面板共享 FIFO 传输，读取完整 JSON 后才发送下一项，最多32个待发请求。GET 仅对503做两次有限重读；POST 固定入队时正文，绝不自动重试。视图使用 generation/version 丢弃切换节点后的迟到响应，而非提前中止仍在服务端执行的 handler。没有硬请求时限；大型历史审计会影响等待时间。

失败提交保留当前页面的原请求 ID 和正文，允许人工原样重发。编辑、切换上下文和重新载入会清理确认；没有跨刷新草稿持久化。网络失败不能证明服务端没有提交，离开页面后应先核对记录。报告读失败隐藏旧组合判断，人工恢复读取后才能重新展示。

沿用同源、CSRF、严格 JSON、192KiB 及原证明语言限制。HTTP 来源描述不发送证明数据；执行器仍从本地受审计工件取数据。目录历史仅返回最近20条摘要并明确总数，完整报告与导出均重新审计。原图16次／480秒与组合200条／单次1–30秒仍分别记账。

本阶段只验证作者可见机制和浏览器交互。未增加依赖、模型调用、一般结构／归纳、自动研究规划或数学原创性评价；本地具名声明、受信宿主与同内核的边界保持。
