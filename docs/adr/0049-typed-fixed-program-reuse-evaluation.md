# ADR 0049：类型化固定程序证明复用对照

日期：2026-10-28。状态：采用，真实结果另列。

问题：已有类型化证明复用工作台能导入已验证数据，但没有明确数学领域的固定预算成本对照。直接目标 grind 与人工引理调用信息不等价，不能用其差异冒称复用的因果收益。

决定：同一完整来源类型、冻结策略程序和显式调用树，比较归档数据导入与调用处闭合程序展开。有理数代数、显式 Nat→Int→Rat、非零条件、归档不可用和量词捕获共六题；作者完全可见、无模型、非训练数据。完整计划具名确认，候选加独立重放，全部失败计分母；import 冷成本包括来源构建。评测私有目录不伪造研究图关联。

实现：新增三个有界模块和独立生命周期，复用原两个真实执行器。冻结旧数学模块、模板和清单。绑定数据与实现；一次执行不自动续跑，工件损坏与来源撤销持续停用统计。CLI 具体入口先于 typed-reuse-* 通用分支。

代价：闭合程序逐次展开会重复 elaboration；导入归档增加检查、扫描和构建成本。规模小、顺序固定、同一内核、作者可见，不能外推提速、原创数学能力或四大期刊难度。后续扩大数学语言和独立持出题集须另行预声明；不根据本轮真实结果悄悄改题。
