# ADR 0050：显式代数结构与受控自然数归纳

日期：2026-10-29（阶段于 10-28 开始）。状态：采用；真实验收单列。

问题：Nat／Int／Rat 闭合定义无法表达任意载体上的运算与结构定律；固定策略不能显式指定归纳。原封存 Mathlib.Data.Nat.Basic 未导入完整代数层级，其源码 assert_not_exists Monoid；直接声称支持 Mathlib 幺半群会失实。

决定：新增 explicit-structures-v1，不修改冻结 typed 协议、数学执行器、模板、导入与政策。至多两个 Type 载体、显式运算／谓词、透明闭合定义和所有结构定律进入完整命题。结构名字不附带任何定律，交换律不会自动添加。局部 Nat.rec 表达自然数折叠；证明程序只支持 rfl、grind、具名有限重写及一次原任务 Nat 变量归纳，显式指定需泛化的变量。

递归计算通过局部 rfl 证明的 Nat.rec 零／后继等式化简；它们是内核检查的局部定理，不是外加公理。原始完整目标仍包含真实 recursor。真实候选检查与独立证明数据重放沿用原执行器，具名确认绑定完整目标、全部条件、定义、程序、预算和实现。失败保持 UNKNOWN。

入口：独立 structure-* CLI 与 artifacts/explicit-structures 账本，沿用全局 worker 锁。旧网页／后台队列与研究图不自动消费新协议，也不把旧 typed 证据改版。每项候选与重放共享 1–30 worker 秒，无重试；最多200记录。

代价与限制：Type 宇宙0、一次 Nat 归纳、非依赖数据类型及有界表达式。未检查条件一致性、结构存在性、自然语言自动对齐或原创性；本地 reviewer 只是具名声明，同一固定 Lean 内核的不同进程并非独立实现。作者可见幂加法、乘法同态和三角数是功能验收，不是模型或四大期刊级研究成绩。
