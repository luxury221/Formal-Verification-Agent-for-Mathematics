# ADR 0051：同项目显式结构与归纳研究图

日期：2026-10-29。状态：采用；实测结果独立记录。

问题：explicit-structures-v1 已能真实核验一般载体及自然归纳，但独立单例尚不能代表项目原问题已解决。旧typed研究图的数学类型、记录schema和实现指纹固定，直接改写会使历史证据失效。

决定：新增 structure-project-research-v1、StructureResearchStore 与独立 checks 适配器，保留旧模块字节。采用本项目既有typed图的生命周期设计，分别固定新schema／路径／ID／manifest，不运行时替换旧模块。共享载体、运算、定义和闭合结构定律；每节点另有完整原条件、目标、证明程序和预算。共享定律不能捕获任何节点变量，编译器仅作闭合作用域检查，不把内部检查请求当数学证据或条件一致性证明。

每个节点真实子命题包含所有共享结构定律和自身原条件；前置仅控制调度和绑定具体证据，不自动添加假设或导入证明项。原问题必须有自己的完整候选检查、类型／公理审计、独立数据重放和父提交。只看PROVED/E4标签不足以开门；另核验实际候选／重放成功审计及独立PID。

保存完整图无需数学确认，不执行Lean；逐节点具名确认绑定父项目／研究线原语境、全图完整计划、当前前置证据和完整子命题。至多50图、每图8节点／16检查／480预留worker秒，取消仍保留额度，不重试。锁、原子记录、工件失效、撤销和保守恢复沿用既有设计。监督进程在子证明提交后、父图提交前退出，子证明和原图结论分别报告，原图不晋升。

代价：独立版本保留部分生命周期代码重复，暂不抽取或重构冻结模块；今后公共实现迁移必须单独评估证据失效与升级成本。本轮只做CLI及同项目协议，旧HTTP队列／工作台不会自动执行新图。后续在现有页面接入完整环境和原问题状态，再扩展证明项复用；不能把调度图宣传为复用收益。

边界：Type宇宙0、一次受控Nat归纳、原白名单和同一固定内核的不同进程；本地姓名非身份认证。作者可见同态保持幂是功能验收，没有模型、独立题集或原创研究能力结论。
