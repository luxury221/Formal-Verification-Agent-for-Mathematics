# ADR 0052：现有工作台接入结构研究图

日期：2026-10-29。状态：采用；实测结果独立记录。

问题：同项目结构／归纳图已有真实 CLI 验证，但网页与后台尚不消费新协议。新增孤立页面会割裂原项目语境；直接改写旧 typed 协议会使历史证据失效。

决定：保留 /typed-research 路由，在现有数学研究工作台内设置“数域与定义／结构与归纳”两种模式。新增 structure_research_web 适配器和 /v1/structure-research HTTP 路由，调用冻结 StructureResearchStore；原单 TaskPump 在最后消费新结构队列，最后可选参数保留旧构造兼容。无第二套数学执行器、依赖或公理。

结构模式展示完整载体、运算签名、递推定义、全部共享定律、局部原条件、完整 Lean 目标和受控归纳程序。预览与保存不执行 Lean；每节点需具名确认完整执行指纹，原问题须自己的候选审计和独立数据重放。前置只调度并绑定证据，尚不导入结构证明项。模式切换向旧 typed 复用面板发布空语境并隐藏该面板，禁止跨协议混用。

沿用同源、CSRF、严格 JSON 和192KiB限制。两种模式共享原 FIFO 传输；GET 仅在503时有限重读，POST 不自动重发。服务端已接受而响应丢失时，本页面保留原 ID 与正文，锁定姓名和确认，人工恢复保持幂等。跨刷新草稿不持久化，用户应先核对已有尝试。模式／项目／节点／编辑变动清除确认并递增 epoch；迟到预览不得建立旧确认。读报告失败隐藏旧数学判断。

代价与边界：页面仍以结构化 JSON 编辑，未接模型自动规划；原服务单队列可能竞争，FIFO 无硬 HTTP 时限。姓名是本地对齐声明，同一固定内核的不同进程不是独立实现。条件命题未证明结构存在或前提一致。旧图和证据不自动迁移或晋升；本阶段只验收真实网页操作，不代表原创研究或四大期刊能力。
