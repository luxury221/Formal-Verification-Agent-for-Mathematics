# ADR 0053：显式结构完整证明数据复用

日期：2026-10-29。状态：采用；实测结果独立记录。

问题：结构图已支持同项目显式载体、运算、定律及真实归纳，但前置仍只控制调度。要积累可组合的数学证明，须在完整原类型下导入实际证明数据，且不能自动削弱目标、增补条件或晋升旧图。

决定：新增 structure-proof-composition-v1、StructureReuseStore 与受限证明项编译器。独立适配复用本项目冻结 LibraryCompositionStore.execute 及原证明数据导入／独立重放模板；不改原结构图、数学执行器或 typed 协议。原图每个直接前置恰有一份同图同节点当前E4来源，可取 node.<structureflow-id>.<node-id>，或新账本 run.<mathlib-id> 的组合E4。来源完整类型与原图目标逐字核对，实际候选／重放审计和不同PID均需存在。

源和目标必须逐字相同的载体／运算／闭合定义；导入的全称类型显式实例化为当前载体和运算，再由请求提供每个数据变量实参及每条原条件证明。不按结构名称自动附加任何定律。量词及 Nat.rec 折叠步变量按词法作用域重命名，保持同时替换，避免目标变量捕获。

受控项包括假设、具名引理应用、合取与投影、等价方向、命题函数应用、等式自反／对称／传递，以及显式函数体 congrArg。没有任意 Lean、tactic后备或模型生成。定义在类型和证明项中以相同环境闭合。新组合完整目标另经候选检查及独立数据重放，原图判断不自动变化。

继承原全局worker锁、事务与有界图读锁等待，仅重试取锁，不重跑Lean；最终递归来源门禁复用同一SQLite写事务。来源撤销／替换／工件或语境漂移使后继持续停用，字节恢复或重证不会复活旧确认。新账本预算与原图分别记账，最多200次组合，单次候选和重放共享1–30秒；不声称统一研究总预算或复用提速。

代价：保留与旧 typed 适配器相似的生命周期代码，以避免改冻结证据；后续重构须单独评估迁移与旧证据失效。当前新CLI先验收，现有网页及HTTP队列不会自动执行新组合；下一阶段接同一工作台。模型仍稍后配置。

边界：Type宇宙0、完全相同共享环境、至多4直接源及原溯源限制；不支持跨结构的载体／运算重命名映射、任意新归纳或自动发现引理。本地姓名非认证；同内核不同进程非不同实现；未证明条件一致性、结构存在、新颖性或四大期刊能力。
