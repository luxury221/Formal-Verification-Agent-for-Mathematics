# ADR 0054：在现有数学工作台集成结构证明复用

日期：2026-10-29。状态：采用；验收证据单独封存。

问题：MRA062 的完整结构证明项复用只有 CLI。网页不能提交该队列，也不能显示完整载体、运算实参与全部条件证明。增加一个孤立页面会重复研究语境，容易误用旧确认。

决定：在原 /typed-research 页面复用同一 tru 面板，按数域／结构语境选择版本化 HTTP 接口。新增 /v1/structure-reuse，沿用同源、CSRF、严格 JSON、192KiB 限额；仅投影来源描述，不返回证明数据。共享 typed_reuse_web 的来源投影和目录历史函数，以显式 origin 参数区分协议。原单 TaskPump 最后增加可选 structure_reuse，兼容旧构造，串行消费新队列。原结构证明编译器、执行器、导入与重放模板保持原字节。

原 mra:typed-context 保留结构模式为空的语义；新 mra:research-context 携带 mode、graph_id、node_id、revision，供统一面板消费。模式／图／节点／编辑会废弃旧确认，世代号丢弃迟到响应。空语境立即清来源、待提交请求及定时器；源读取循环也受世代约束。

结构面板完整显示载体、运算签名、定义正文、全部原条件和目标。每次调用显示显式环境实参、变量替换、每条实例化条件及对应证明项。congr 只接受协议内的显式变量、函数体和等式。来源和目标环境必须逐字相同，不进行跨载体映射。目录与预览为 UNKNOWN/E0；新组合 E4 和原图判断分开，预算分别计账。

写请求只发送一次。响应丢失时在页面内锁定原正文、核对人和确认框，人工使用同一请求 ID 恢复；编辑或换语境即放弃该页面内请求，应先查已有历史。跨刷新草稿仍未持久化。读失败隐藏当前旧判断；历史最多显示20条、总账本最多200条。取消与具名撤销沿用核心生命周期。

代价与边界：适配器仍须维护两种协议路由；完整结构和八条条件需要滚动核对。锁竞争时完整性审计可能返回503，保留有界 GET 重读与人工恢复，不减少数学门禁。本地姓名只是语义声明；两进程使用同一固定 Lean 内核。无新依赖、模型接入配置、训练、一般结构存在性或原创研究能力声明。
