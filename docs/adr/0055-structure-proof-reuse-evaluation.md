# ADR 0055：结构证明复用的固定程序领域诊断

日期：2026-10-29。状态：采用；实测另记。

问题：结构与归纳已具备完整证明数据复用和网页操作，但通过演示不能判断复用成本，更不能据此推断重大原创研究能力。

决定：新增独立 structure-proof-reuse-evaluation-v1，在显式幺半群、同态与自然数幂范围固定六个作者可见案例。完整来源程序、目标、全部定律和显式调用树对两组一致；import 构建来源后导入真实证明数据，inline 每次调用展开同一完整闭合来源程序。来源和内联均在引入自己的绑定前依赖逆序清除冻结编译器可产生的调用者局部变量，另用真实矛盾外层假设探针检验隔离。

每项候选及独立重放共享30秒；每题每组最多两项／60秒；五份可尝试来源、五份可尝试导入、六份内联合计最多16项／480预留worker秒。inline实际只用一项，不挪用未用额度。固定上限并不意味着同量搜索。缺来源、错误条件和缺交换性均保留六题分母；UNKNOWN不得当反例。来源构建计入import冷成本，目标成本另列。

使用原 MathlibLabStore.execute、LibraryCompositionStore.execute 及原导入／重放模板；新私有适配器不写原研究图或主复用账本。共享旧typed评测纯统计与阻塞函数，绑定其摘要；独立版本保留相似生命周期代码，代价是重复维护。此时抽取公共执行生命周期会改变旧证据语境，留待独立迁移阶段。

计划、来源、程序、预算、完整运行上下文和具名确认绑定。中断后不自动续跑；同确认幂等，损坏、撤销或漂移持续停用统计。父报告始终UNKNOWN/E0；完整子目标成功才有E4。另修复现有页面忙碌时节点按钮可点击的反馈，并明确原图与组合判断。

边界：这不是独立持出题集、模型解题率、随机对照或显著性试验。固定小程序的成本不能推断一般提速或四大期刊能力。来源与目标环境必须逐字相同；同固定内核不同进程不构成独立实现。本地核对人姓名不是身份认证。无新依赖、训练或外部模型调用。
