# ADR 0056：完整结构目标的有界候选程序与真实反馈

日期：2026-10-29。状态：采用，实测单独记录。

问题：结构研究图已有真实归纳、证明数据复用与全分母成本记录，但仍要求人工填写每个归纳变量和定律改写步骤。重复演示不能替代候选生成能力。

决定：增加 structure-strategy-proposals-v1 纯候选接口，从完整目标（不含参考证明）、原有等式定律及透明定义出发，使用有界广度改写和单层Nat归纳提出结构化程序。优先最后声明的Nat变量，不依赖题名或定律名称；没有自动泛化变量、添条件、新引理或任意Lean。Python计算只作启发式，不赋予证明状态。固定rfl/grind尝试明确标记，与符号生成来源分开。

候选用完整原编译器校验和完整目标逐字核对，恒UNKNOWN/E0。预算包括候选数、改写步数、展开次数、0.75秒合成检查点、32768规范化访问及替换前4096中间数据节点估计；有限搜索不完整，超限仍返回已产生的有界候选。准备及完整性读取耗时独立于合成及后续worker预算。

现有结构节点HTTP路由增加只读意义的POST strategy-proposals（沿用同源、CSRF及严格JSON），从保存图读取完整节点和当前真实子检查，不接收客户端伪造反馈。失败、取消、撤销和未知保留；仅对当前有效REJECTED的同一程序排序靠后，不从失败推断命题错误，也不隐藏失败。反馈按图、节点、完整目标及revision绑定。

网页在同一工作台显示候选及可展开反馈；应用时只替换该节点草稿中的proof，保留其他节点、全部定义、载体、运算、目标和原条件。编辑、换节点／模式或版本变化清候选与旧确认；迟到响应不能覆盖草稿。必须预览并另存图，再在原具名节点确认流程执行。没有新数学执行器或检查账本，原StructureResearchStore及候选／重放模板字节不变。

代价：符号正规化／首个匹配的近似可能与Lean展开和rw不同，某些候选会被真实检查拒绝；这是可审计的程序建议，不是可信证明搜索结果。仍是小范围幺半群／同态／自然数递推能力，不是一般交互式战术、模型规划、独立盲测、原创性或四大期刊能力。

自审：无执行探针暴露嵌套改写闭包错误重绑定规则变量，已在真实执行前修正并保留源码／错误候选；缺交换性与具体两步改写契约覆盖该错误。透明定义可能指数展开，替换前先估算并限额，另有对抗测试。数学结论只由原真实检查和独立数据重放决定。
