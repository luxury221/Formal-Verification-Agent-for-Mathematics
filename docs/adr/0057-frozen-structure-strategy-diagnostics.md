# ADR 0057：冻结候选程序、同 Lean 预算的结构策略诊断

日期：2026-10-29。状态：采用，实际结果另存。

问题：MRA065 已能提出程序，但少量作者示例的通过不足以比较策略。需要固定完整分母、保留失败、明确题目曝光、冻结已准备候选，并把准备和真实核验的成本分别记录。

决定：新增独立 structure-strategy-evaluation-v1，固定六个案例、五个相关任务族。题目来自本仓库已公开给开发过程的作者示例，记录本地来源路径及摘要、原例索引、变换、曝光和 reference_proof_excluded；不声称持出或独立测试，也不宣称这些作者元数据有第三方认证。幂加法原式与变量声明顺序变体属于同一任务族，不能视为两个独立数学成果。

两组每案例最多两个程序、每个程序候选与重放共享20秒，故每组每案例40秒、全组六题240秒、两组480秒、最多24完整检查。固定组顺序rfl/grind；生成组取冻结MRA065生成器预算4步／800展开／2候选的输出原顺序，不按真实结果调优或补程序。生成组也包含生成器默认的rfl，不给它额外尝试。按案例交替先执行哪组；一组取得当前完整E4后跳过其后续槽位，不挪用剩余额度。

prepare只生成、编译和保存完整候选快照，不运行Lean。具名确认绑定已准备的完整目标、程序、来源和预算；run单次持有原全局worker锁，逐个调用冻结结构执行器。读取report不重新调用生成器，避免时间限额造成候选漂移。真实子检查须有完整类型、公理与独立进程审计，不能只凭E4标签停止搜索或计入成功。所有原目标与全部原前提保持逐字相同。

24个预声明槽位全部保留，明确区分实际检查、成功后跳过及未提出候选；每组分母恒六。父评测恒UNKNOWN/E0，子证明独立记录，不写原研究图或主证明库。中断或执行错误不发布汇总，不自动重试／续跑。工件损坏、撤销、版本或题目变化使整份比较持续不可用，还原旧字节不复活统计。

计时边界：Lean预算相同不等于CPU或端到端总成本相同。分别记录生成器合成／准备、计划构造、prepare完整调用、真实检查worker／墙钟、run完整调用及report审计。计划构造时间不包含后续保存与审计；准备返回的调用时间包含这些阶段，但不含CLI进程启动与JSON输出，实际CLI包装器另记调用墙钟。不得据固定小题与少量计时宣称总体提速或统计显著性。

本阶段新增CLI prepare／run／report，沿用现有工作台及执行器，不增加独立网页。冻结旧生成器、编译器、执行器、导入重放及旧评测协议。没有新外部依赖、模型配置或调用。下一步按真实失败定位可改进的策略，再用另立且记录曝光的任务集验证，不能通过调整本题集掩盖失败。
