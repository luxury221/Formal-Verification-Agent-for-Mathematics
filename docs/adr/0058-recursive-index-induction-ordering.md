# ADR 0058：按目标递推索引排序归纳变量

日期：2026-10-29。状态：采用，真实结果另存。

MRA066 的幂加法声明换序变体保持 UNKNOWN。冻结生成器按 Nat 变量声明逆序尝试归纳，在有限候选及展开预算下，先尝试无效方向可能耗尽搜索。仅改声明顺序不应成为策略优先级的数学依据。

新增 structure-strategy-proposals-v2，RankedPlanner 复用 v1 的规范化、捕获规避替换、定律匹配、有限改写搜索与资源检查点；另行实现程序组装和归纳排序。v1 生成器、旧题集、旧评测及所有数学检查核心保持原字节。新版 CLI 使用 structure-strategy-v2-plan/node，HTTP action 使用 strategy-proposals-v2。现有工作台默认使用 v2，不增加独立页面。

有界展开完整目标中的透明定义后，仅收集活跃 nat_fold 的索引，遍历索引及零分支，跳过悬置 step.body；不扫描未使用定义作为归纳触发条件。对每个索引中的顶层自由 Nat 变量，分别替换为零和内部后继并规范化，累计可暴露的零／后继分支数。优先后继、其次零，再按规范化目标 AST 中自由变量首次出现顺序排序；不按标识符名称或声明顺序。此为启发式，非数学充分条件；量词及 fold 绑定按词法作用域排除，原目标及所有原条件严格保留。

排序和搜索共用 0.75 秒检查点、32768 规范化节点、4096 替换前表达式估计及 max_expansions。超限保留已经产生的固定候选，ranking_complete=false 表示排序未完成；所有候选及计划恒 UNKNOWN/E0。不增加泛化、自动引理、模型、依赖或 Lean 特权。

新增作者可见诊断，保存本地来源、变换、曝光和完整无 proof 目标。真实配对方案提前冻结：三例、两组，分别取第一个非 rfl 程序，一次完整检查，候选与重放共享20秒；不重试、不挪用预算。旧声明换序回归单独在实际浏览器中走 rfl 失败、v2 草稿、另存、具名确认与真实验证。新口径不改写 MRA066 两候选六题结果，也不称持出或独立研究能力。

候选只修改当前节点草稿 proof；旧失败图继续保留。新图必须完整预览、另存及具名确认，经原候选与独立证明数据重放、完整类型和允许公理审计，才能获得自己的 E4。当前保存图的真实反馈由服务端读取，客户端不能上传反馈。编辑、迟到响应、节点／模式切换继续清除旧上下文。
