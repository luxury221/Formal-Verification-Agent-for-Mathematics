# ADR 0059：完整目标的有界原参数泛化

日期：2026-10-29。状态：采用，真实结果另存。

现有受控证明编译器支持显式 generalizing，但 v1／v2 候选始终 generalize=[]。重复变换的作用与抽象递推模型一致这一条件命题中，后继分支把初态变为apply(f,state)，归纳假设需要能实例化到该初态。只改善归纳变量的排序不能代替更强的归纳假设。

新增 structure-strategy-proposals-v3；冻结现有编译器、执行器、导入／重放、v1／v2生成器和历史诊断。GeneralizingPlanner 继承 v2 活跃索引排序，使用原有规则、规范化和预算。只考虑归纳假设中自由出现的其他原目标变量；若原前提自由依赖该变量，或变量位于fold／量词绑定子项之内，则保守排除。未出现的无关原变量不进入选项。

优先共同泛化所有合格参数，再逐个单参数，最后不泛化；选项去重，最多原变量上限8减去归纳变量，即7参数。没有增加原目标变量、假设或引理。泛化IH用有类型的原参数作匹配变量；绑定子项仅在不含待匹配参数时按词法alpha等价比较，否则拒绝，避免捕获局部变量。只扩展候选匹配器，不扩大可信证明语法。

排序和各泛化方案共用0.75秒合成检查点、32768规范化访问、4096替换前表达式估计、展开次数、最多6改写步／8候选。不能因增加选项获得额外搜索燃料。超限保留已得候选，未完成方案没有成功保证。候选仍全部UNKNOWN/E0；symbolic-generalized-induction只表示近似搜索路径，不能赋证据。

新CLI structure-strategy-v3-plan/node、新HTTP action strategy-proposals-v3接入同一工作台；旧接口保持旧行为。工作台显示原参数泛化及保守排除提示，完整细节可核对；只带入proof草稿，须重新预览、另存新图、具名确认并由原执行器检查完整原目标。

新作者可见诊断包含单初态、重命名换序、二初态观察及删除模型后继条件。三题两组取各自首个非rfl程序、每组每题一次完整检查、候选／重放共享20秒；提前保存候选，交替组顺序，不重试。重命名变体通过实际浏览器走原rfl失败与新泛化候选另存。全部同源相关，不能称持出、独立研究能力或数学上所有不泛化证明都不可能。旧MRA066／067成绩不回写。

当前排除原前提依赖和绑定内部变量，属于明确受限的候选功能；尚未合成需要回退依赖前提的泛化、嵌套归纳、自动引理或模型规划。没有外部依赖或模型调用。下一步应评估必要引理选择与分支诊断，继续保留原目标与真实证据边界。
