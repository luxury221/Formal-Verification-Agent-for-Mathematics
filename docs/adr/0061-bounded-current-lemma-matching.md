# ADR 0061：当前已证引理的有界完整调用建议

日期：2026-10-29。状态：采用，实际验收结果另存。

原结构候选可做单层归纳及受控泛化，但现有证明复用仍要求手工填写每个来源、实参和条件证明。本轮增加 structure-lemma-suggestions-v1，只提出结构化证明调用，消费冻结原StructureReuseStore；不扩大可信证明语法、不修改旧源门禁、不改原图判断。

建议只使用同图直接前置的当前真实E4节点或组合run来源，逐份调用原load_source重新核对完整类型、工件、祖先及撤销。每个直接前置最多两个可用来源，最多八份来源审计和八种组合；每份已声明来源必须实际使用。来源读取和完整性时间单独记账，不冒称0.75秒端到端服务。

搜索以有类型模式匹配确定来源变量，未确定参数只枚举完整目标的有界数据子项和原变量，不猜测新公理或补前提。绑定子项沿用保守词法匹配，不把局部变量加入自由实参池。条件可通过原假设、自反、合取或其他已证引理的显式调用证明；等式可在绑定子项外反向改写、经函数合同及传递闭合。每个实参和每条原条件都出现在生成程序及应用明细中。

默认深度4、等式改写3步、32数据子项、1600展开、4候选；上限6／4／64／4000／4。所有来源组合、递归条件和等式分支共享原0.75秒搜索检查点及展开计数，替换前沿用4096估计。不是完整搜索，所有候选和未闭合条件恒UNKNOWN/E0。原图真实检查错误单独从当前账本读取，符号推演条件不能声称为Lean返回的失败分支或数学反例。

同一工作台复用面板增加显式匹配按钮、建议及条件推演明细。选择后重新读取全部来源并对比建议指纹，只带入草稿并清旧确认；须经过原完整预览、具名确认、真实证明数据导入与独立重放。语境、来源、预算或正文改变丢弃建议与旧确认；不自动提交或重试。CLI及同源严格HTTP使用同一协议。

作者可见诊断分别覆盖已有幺半群幂引理的实例化／合同改写，以及两项条件函数合同引理的嵌套调用。缺少a=b而只保留a=a时不自动补条件；真实负例需原执行器拒绝错误条件证明。来源撤回后建议和旧组合分别接受原持续失效门禁。它们不是盲测、新颖性或四大期刊级能力证据。没有新外部依赖或模型调用。
