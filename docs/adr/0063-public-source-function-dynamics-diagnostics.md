# ADR 0063：公开来源函数迭代领域对照

日期：2026-10-29。状态：采用，实际结果另存。

MRA066原六题源自本项目自编例子，未检验最新v3生成器在有外部出处的领域任务中的用途。新增版本隔离的function-dynamics-evaluation-v1，固定八题、六个相关任务族：固定点、不变量、半共轭、二元运算保持、交换迭代以及删除半共轭条件的负对照，并增加迭代次数相加与交换复合迭代两道结构挑战。七道正向任务为固定Mathlib版本陈述的Type0／点态／显式Nat.rec改写；来源与许可证按准确上游commit字节核对。改写本身须具名对齐，不冒称已验证与上游定义的等价桥接。

旧v1与当前v3各最多两候选、800合成展开、4步改写；候选／独立重放共用20秒，每题每组最多40秒，八题双组最多32检查／640秒预留worker。两组生成成本分别保存，不宣称总CPU或墙钟预算相同。交替组顺序，首个真实完整E4后跳过未用槽，所有题与槽仍保留分母。报告只审核已冻结程序，不重做搜索，不补试追分。

开发者已看原陈述和相邻证明；所有题均开发者可见、不是独立盲测。候选生成器仅收到完整改写目标和预算，未提供Mathlib参考证明、题目来源文字或原定理名。不用于训练，无模型调用或新依赖。旧题、生成器、执行器及历史分数不改。

使用独立私有评测目录和检查账本；沿用原完整目标／公理政策及不同进程证明数据重放。具名确认前不创建检查账本；中断无自动续跑或补发，真实子E4不能代替父评测完成。来源、版本、程序、预算、证据损坏／撤销持续停用统计。报告父恒UNKNOWN/E0，子证据逐项展示。没有扩大任意Lean或宿主执行权限。
