# ADR 0064：有界预算下的词法匹配与候选取舍

状态：采用；2026-10-29，MRA072。

MRA071 的两候选预算始终被 rfl 与同一个归纳程序占据；旧 v3 保守排除所有出现在折叠子树内的参数，不能证明新版本有覆盖优势。保留 v1/v2/v3、旧题集、旧分数及数学执行器，新建 v4，显式选择使用。

v4 在全局原燃料内给每次符号改写搜索分配局部配额，先尝试直接闭合，再按轮次尝试不同归纳方向的泛化选项。符号搜索闭合的程序先选；未闭合程序先保留各归纳方向的最佳已有分支，再选同方向额外变体，grind/rfl 为末尾备选。每次局部配额为 min(128,max(8,总展开预算//8))；实际计数包括触发局部退出的检查点，总计不超过全局预算。0.75 秒为合成检查点边界，准备、编译及完整性审计另计。

自由规则参数可以匹配递归或量词子项中的自由项。局部绑定变量按相对词法深度对应，类型列表须一致；任何依赖当前局部绑定变量的实参都拒绝，重复实参要求 alpha 一致，失败不提交部分匹配。替换仍调用原捕获避免替换器。允许原等式的整个绑定子项匹配，但不进入绑定体执行改写。原前提自由依赖继续排除泛化，完整目标不增删条件。

CLI 新增 structure-strategy-v4-plan/node；现有网页和 HTTP 保留旧 v3，本轮没有新的浏览器验收或自动执行。候选含可复核的选择记录，但始终 UNKNOWN/E0。符号预测可能与 Lean 的 rw 匹配次序不同，真实执行器及独立重放才决定证据。

另立六题诊断：四题为作者可见的新机制任务（两次交织、索引递归不变量、递归原等式传输、删条件）；两题明确沿用已知失败的次数相加／交换复合。真实结果前固定原目标、2候选/800展开/4改写、每候选与重放共享20秒；成功后保留余槽为跳过，不额外补试。不是盲测或独立难题成绩，不能把原等式传输案例当成自动发现该等式。

无新增外部依赖。对原创研究的下一障碍仍是多步引理计划、嵌套归纳与更广数学表达；本次实现不推导必要引理或前提一致性。
