# ADR0065：受控算术改写与经检查的局部递归引理

2026-10-29，MRA073，采用。

MRA072 的次数相加在 n/m 两种归纳下均失败。实际旧编译器只规范 Nat.add_zero/add_succ，不能反映左侧递推。交换复合的完整程序还缺少可使用的迭代交换引理；仅扩大grind燃料不能保证取得证明。

新建 structure-recursion-program-v1 语言及独立存储，复用原 MathlibLabStore 的完整类型检查、单worker锁、候选与独立证明数据重放、公理政策、取消和中断门禁。旧结构编译器、v1/v2/v3/v4生成器、旧来源身份及旧分数保持，CLI显式选择新模式。

新证明编译器把 Nat.zero_add、Nat.succ_add 加入原固定算术／recursor等式集合，非归纳程序直接规范；归纳程序只在分支内部规范，保留归纳前构造的recursor计算引理。两定理取自已固定Lean4.35.0的Init/Data/Nat/Basic.lean:135/142，运行时Apache-2.0许可及本地源摘要见本轮dependency-review.json，无新外部依赖。符号归一化只提出程序，不能证数学结论。

程序可声明最多两个局部引理，每个引理包含名称、目标AST和受控proof。它们共享原载体、运算、定义及全部原条件；只能使用原变量中目标实际需要的变量。目前带局部引理的程序要求原条件不自由依赖目标变量。引理各自先形成完整闭合定理并真实证明，后续程序只引用已先行声明者；禁止自引、前向引和新增条件。主目标的全部原变量／条件／形式类型不改变。helper里继承的original字段仅保留主问题语境，真正局部义务以显式goal及完整形式类型为准，不能把它当用户另行断言。

自动建议识别原显式一变量交换等式，以及具有两参数、无索引依赖步进的原始一元fold定义，提出“交换函数穿过fold”的局部义务。每候选至多一个自动helper；手工结构程序上限两个，允许每个各做一次Nat归纳。模板不使用外部参考证明，不能称通用引理发现。

默认2候选/800展开/4改写，所有主／helper搜索共享总展开、32768归一化节点、4096替换前增长限额及0.75秒检查点计时；每个搜索段最多使用总预算的约三分之一。段间编译同样消耗共享计时，最后的编译／完整性准备没有端到端硬时限。输出各段计数，不给模型或候选自报E4。

另立六题：两道旧已知障碍、嵌套初态相加、正确位移的索引递推、删交换条件及观察映射复合压力题。前两道明确沿用已知失败，不作盲测；其余作者可见，相关任务不当独立任务族。先冻结全部目标与双组程序，再按题交替v4/新程序，最多两次共享20worker秒，成功后保留跳过槽。另做真实错误helper、重放后取消、监督退出不发布／不续跑。

当前为CLI，无新HTTP或网页入口。原图、旧组合以及新局部程序的判断分别保存；内联helper没有单独持久E4源，未来跨图复用需要另立明确的导出／条件绑定协议。

验收中曾实际发现编译器的无变化simp失败、let定义错误引入及归纳前化简消耗计算引理，均保留原始失败并修复。修复不改变六题及候选请求程序；最终内核源按修复变化。初轮内部摘要过早写通过，外层真实测试明确失败；最终先检查必要目标再生成通过字段。另立两引理串联辅助案例，不并入六题分母；详见本轮验收报告。
