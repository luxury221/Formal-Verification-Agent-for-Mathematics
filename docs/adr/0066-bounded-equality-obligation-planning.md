# ADR0066：完整目标的有界等式义务规划

2026-10-29，MRA074，采用。

MRA073观察映射复合目标的直接归纳后继分支失败，不能把观察后的等式当作观察前的等式。新建structure-recursion-proposals-v2生成器与structure-obligation-propose CLI，旧编译器、v1生成器、题集及来源身份保持。输出仍是structure-recursion-program-v1，由原执行器检查全部引理及完整主目标。没有新外部依赖，也不做持久引理导出或前端集成。

只在等式双方具有同一项构造且恰好一个对应参数不同时，提出该参数的等式作为更强的充分证明义务。支持同名函数调用、数值加减乘除、负号及同目标类型的显式转换；最多8层，不进入量词、recursor绑定体或逻辑公式，不假设任何函数单射。原条件自由依赖目标变量时不造局部引理。最深义务先用原算术/归纳搜索，必要时再证明原显式交换定律导出的fold交换引理；随后把内层主等式作为第二个已证义务，再明确改写完整原目标。两引理均必须通过同一个真实候选和独立重放；原完整类型不增加假设。

全局2候选/800展开/4改写默认值保持；所有义务搜索共享总展开、32768归一化节点和0.75秒检查点，搜索计划本身也耗一展开，每段最多约四分之一总燃料；固定最多8层语法分解单列。准备/编译没有端到端硬时限。不为每个引理重新计时或给免费worker预算。每个完整程序仍候选/重放共享20秒。未找到更强证明时保留完整目标后备，不能把更强义务失败当成原命题失败或反证。

八题在首个真实结果前声明：沿用观察复合已知失败，加多层观察、二元参数、观察相加、观察索引位移，以及删条件、不同观察函数、非单射反向推理对照。作者可见且相关，非盲测或独立研究能力证据。双组逐题交替，每组每题2槽，完整E4后跳过仍保留；本轮固定8题×2组×2候选=32槽，名义预留640 worker秒。只比较原完整目标，不只检查中间义务。
