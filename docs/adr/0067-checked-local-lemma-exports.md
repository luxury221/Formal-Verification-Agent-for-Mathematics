# ADR-0067：局部引理独立检查与跨任务复用

状态：实施；2026-10-29。

MRA074 的内联局部引理属于完整父程序，不能仅复制 E4 标签成为永久知识。采用独立导出协议，从 canonical RecursionStore 当前完整 E4 选取一个具名 helper，保留父环境、全部原变量、全部原条件，重建以前置 helpers 为局部义务、selected proof 为主证明的完整程序。导出重新运行候选与独立数据重放，要求新的具名语义对齐。

导出与应用使用独立 SQLite 账本，固定来源链为 parent → export → application；应用不能成为新来源。父来源没有用户可选路径。Python 构造器的私有 base/parents 注入仅供本项目验证，不能通过 JSON/CLI 选择。新库互不相同，避免终态事务同库递归死锁。

应用使用既有结构组合编译器和真实 proof.ndjson 导入器。每个源变量和原条件都要显式提供项/证明；载体、运算和定义须完全一致，目标变量可改名并实例化。不会把已证命题添加为新假设。导入在候选进程内执行内核检查，完整新目标由另一个进程数据重放。两进程仍为同一固定 Lean 内核实现。

来源身份绑定完整 plan、alignment、files、result、submission fingerprint。父源/导出源每次复核仍需完整当前 E4；撤销或损坏在访问后代时持久降为 UNKNOWN，恢复文件不会自动复活。暂时 WorkerBusy/SQLite busy 传播为暂忙，不能永久判坏；监督退出须显式恢复为 INTERRUPTED/UNKNOWN，再次 work 不自动重跑。最终提交前重新核对来源。

不改旧编译器、生成器、题集及分数，旧 canonical 递归库仅追加新父证明。无新增外部依赖；沿用项目已固定的 Lean 4.35.0 / Mathlib 与标准库。网页未接入新协议；后台也不自动扫描新队列，需显式 CLI work。不能据此次机制验收宣称通用引理发现、独立模型能力或原创数学研究能力。
