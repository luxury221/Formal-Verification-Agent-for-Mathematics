# ADR-0069：从完整新目标发现独立导出引理

状态：实施；2026-10-29。

MRA076已接通手工独立导出与跨任务应用，仍需用户先知道来源ID并手填所有实参/条件证明。新export-lemma-matching-v1在完整新目标下扫描canonical导出库，沿用既有LemmaSearch生成不可信应用数据，接入原工作台第三步与structure-export-match CLI。既有同图直接前置建议协议和全部证明执行器保持。

最近200条账本记录仅作候选目录；原始E4标签及运算名重合只用于语法排序，不能成为数学事实。按固定顺序最多重新复核8个相同载体/运算/定义的来源，load_source必须通过当前完整类型、公理、来源链及真实工件门禁。损坏/撤销排除，暂忙向上传播，不能用部分来源结果冒充完整复核。目录或复核截断明确标记。

搜索沿用有界类型实参池、同时自由替换、原假设匹配、递归条件义务、合取、等式对称/传递及绑定体外合同。所有来源共享同一搜索fuel和计时检查点，最多四个候选、四个实际使用的导入来源；来源复核和最终编译另计，非端到端硬时限。只导入实际使用来源，每项原条件都要显式证明；不增加假设、不跨环境改名、不修改完整目标。

候选先用既有composition编译器核对完整目标/类型，保持UNKNOWN/E0、不写检查账本、不执行Lean。选中后重新调用当前应用preview，对比所有当前来源指纹，再具名提交原执行器真实导入和独立重放。来源在执行前/晋升前继续复核。编辑目标会清候选与确认，晚回应按原epoch丢弃；POST不自动重发。

示例从当前核验的独立等式导出构造原式与反式的合取，显式披露已知来源和非盲测，继承精确环境描述。不能通过修改原定义元数据使示例表面匹配；缺当前来源时报告不可用。新功能不自动晋升或关联原项目图，不以来源名字暗示真假。

验收固定六个作者可见的衍生目标，与旧obligation-v2无导入程序分别真实检查。每目标每组最多两次、每完整检查20 worker秒；两组搜索fuel不同、已有来源的证明成本与来源审查另列，禁止描述为端到端同预算或一般提速。原沙箱输出上限保持，溢出须披露运行错误，不能当数学反证或隐去分母。最终范围见[验收](../evaluation/export-lemma-matching-results.md)。
