# ADR 0076：项目语境下的微积分研究工作台

2026-10-29，MRA084。状态：已实现并完成本阶段集成验收；最终工件摘要见同阶段delivery.json。

用户优先分析与偏微分方程。MRA083已提供受控微积分语言与独立真实验证，但研究项目和网页尚不消费它。本阶段补齐项目语境、完整目标图、具名逐节点执行与网页入口；不修改封存的微积分编译器、运行树、旧类型/结构图或原验收分数。

选项：把微积分强行编码为旧Nat/Int/Rat图会改变原语义；复制整套执行器会重复维护验证逻辑。选择新增calculus-project-research-v1，继承已封存图生命周期中与数学域无关的方法，使用独立graph ID和私有CalculusStore叶账本。新manifest绑定微积分provider、实际继承来源与辅助闭包。每节点完整请求都含原变量、全部前提、测度、端点、证明程序及1–40共享worker秒。

前置只控制顺序并绑定确切当前证据身份，不导入引理证明项、不增加假设、不自动证明原问题。原问题必须有自己的真实候选与独立重放。新图按同文件系统目录rename一次发布，失败准备留在隐藏目录；缺少子账本禁止自动重建。原项目问题或分支语境改变、证据撤销、损坏、旧字节恢复仍持久失效。每图最多8节点、16检查、480预留worker秒，完整性扫描另计。全局单worker与既有队列串行，不自动重试。

新增/analysis网页、严格同源HTTP与显式CLI。预览/保存恒UNKNOWN/E0；运行与数学判断分开，切换项目、编辑输入、暂忙或读取失败清理旧确认和旧判断。POST不自动重发；具名确认仅是本地声明。完整条件和Lean陈述可见，原始数据可展开，导出为研究记录而非声称打包所有证明文件。

验收包括：图范围/条件/类型/测度保持、预算、阻塞、幂等、取消、撤销级联、恢复不复活、原目标未被前置偷换、原子发布、真实HTTP与单worker、实际Lean/重放及桌面/窄屏浏览器。mock仅为协议测试；已知输入不是盲测或原创研究。MRA083两未完成目标及旧回归波动保持历史，不扩大原预算重跑。

回退：停止新队列并取消未开始的新任务，恢复已保留的HTTP路由和导航来源，保留新账本、失败和失效标记；继续使用旧入口。不得删除工件或将新证据移入旧协议。本阶段不声称已实际执行整项目restore/升级/回滚。后续更改新manifest需发布新身份或令相关证据失效，不能就地改写既有E4来源。


验收记录：257项相关回归208通过/49跳过；12质量命令通过；单独真实图/HTTP专项通过（857.806秒），14条实际CLI通过；实际Edge桌面/390px浏览器14项通过。详见[结果](../evaluation/calculus-research-results.md)。没有新依赖或旧数学题组重算，PDE仅源码预查。
