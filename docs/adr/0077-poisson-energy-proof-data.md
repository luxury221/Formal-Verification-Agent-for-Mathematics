# ADR 0077：一维 Poisson 恒等式的独立环境与证明数据复用

- 日期：2026-10-29。
- 状态：已实现，数学验收以本阶段真实专项与结果报告为准。
- 范围：A3 的首条经典导数/边界积分链，不代表 A3 整体完成。

## 决策

使用独立 pde-energy-v1 环境，固定 Lean 4.35.0 和 Mathlib 56a005855ea17e0b0958f73ec801ae140b0a1679。只增加 IntegrationByParts 有限 import；普通复制旧树，不共享可写硬链接，不修改旧分析/微积分环境。使用前 adoption 记录版本、八项依赖许可、用途和限制；官方缓存计划、上游 Cache 源码对照、复用与下载摘要分别保留。

引理链为分部积分 → 零端点 Green 恒等式 → Poisson 测试函数恒等式 → 能量恒等式 → 带端点顺序的非负性。每个后继指定确切源 run ID，读取当前有效 E4 的完整证明 NDJSON。复用既有 lemma-import 模板，在候选进程中对全部声明重新进行内核检查和命名隔离，用完整源定理类型建立桥接。随后检查结果定理直接使用了 checked 常量，并在另一进程重放包含依赖的完整结果。

源记录绑定完整类型、request/result 摘要、运行环境与证明数据摘要。重新读取源与传递依赖；上游损坏被观察后永久失效，恢复原字节不能复活下游。前置图调度和证明项复用仍是不同能力，本接口不会改变旧 /analysis 图的协议。

## 条件与边界

正式目标保留每个 HasDerivAt、IntervalIntegrable、方程和两个边界条件。分部积分使用 Lebesgue volume，有向恒等式不添加 a≤b；非负性必须显式添加 a≤b。入口名 smooth 不表示已经形式化 C∞：确切正则性由目标中列出的经典导数和可积性条件决定。

这是作者已知结果的验证与复用，不是未见题、原创成果或模型成绩。不证明存在性、唯一性、高维推广、弱导数、一般 Sobolev 空间或弱解。也不以积分总定义的默认值代替可积条件。

## 验收与限制

参见 [协议](../protocols/pde-energy-v1.md) 与 [结果](../evaluation/pde-energy-results.md)。每个已声明案例只尝试一次，候选和重放共享 40 worker 秒；完整性扫描另计。取消、超时和中断不发布数学结论，恢复必须在全局锁内显式执行，不自动重试。具名语义对齐仍是 local-assertion-only，两进程使用相同 Lean 实现。

本阶段旧 streaming 扫描器回归发现元数据竞态，诊断及原失败保留。新入口使用既有 ContentSnapshot，未替换旧执行器；同宿主恶意并发写入不在受保护边界内。不能声称修复旧扫描器或所有回归全通过，后续修复应使用新身份并验证对历史证据的影响。
