# ADR-0079：受控经典 PDE 语言与确切证明来源

日期：2026-10-29。状态：已按本轮明确范围验收；保留旧scanner回归失败，不代表全项目或一般PDE完成。

## 问题

固定 Poisson catalog 能证明已知恒等式，但用户不能陈述新的完整目标。
分析研究图的调度前置也不能自动充当 Lean 假设。需要有界、可编辑的输入，
并在新目标中真正应用已检查的证明数据，保持全部原条件及来源撤销关系。

## 决策

新增 pde-language-v1、pdelang- run ID 与独立 SQLite 身份；不迁移已有账本，
不修改已产生 E4 的编译器、profile 或数学环境。复用不可变 IntegrationByParts
环境，独立 adoption/acquisition/snapshot/lock，实际采用 watched 全字节校验。
新增导入已有缓存的 InnerProductSpace.Basic，使继承的实数内积估计规则实际可用；
不下载、不修改旧树，也不扩大旧profile的导入范围。

语言采用显式实数、Real→Real 函数、测度、闭区间导数、可积性与词法绑定。
保留原全部条件，包括未使用条件。source_apply 必须选择确切 run ID、
完整类型 digest、所有实参与条件证明；来源仅限当前有效 watched 固定结果，
或同一新账本中的当前 E4。每个来源需在最终结果证明项中直接出现。

导入 NDJSON 而非候选模块；在候选进程内核核对完整来源类型和公理，
导出依赖闭包后在另一进程重新核验完整新目标。预览、代入和候选均保持 E0。
只有实际两阶段检查、完整工件和具名语义对齐均满足才给新任务 E4。
具名确认是本地声明，不是身份认证或独立数学专家审查。

来源每次重新审计；单次递归限制为8层及16个不同 typed run，
固定来源自身仍执行其有界 catalog 检查。没有跨请求的成功缓存。
发布前重新核对来源，事务内再次比较原目标、确认、状态、撤销标记与持久来源身份。
观察到损坏或撤销后永久失效；恢复原字节不重新授权。

## 限制与后续

首期提供显式 CLI；网页/研究图后续接入，不改变原 /analysis 执行器。
当前证明程序包含显式来源应用、等式重写、积分合同、积分负号及非负规则；
不接收任意 Lean、imports、axioms 或用户战术文本。每项候选与重放共享1–40秒
Lean预算，完整性与来源审计时间另计，无自动数学重试。

经典一维 Poisson 条件恒等式不是一般弱解定义，不证明高维、存在性、唯一性、
边界迹或原创性。Bochner 积分和 deriv 的总函数约定不提供可积/可导证据。
非负积分需要端点顺序。已有模型接入计划仍保持用户稍后本地配置。
