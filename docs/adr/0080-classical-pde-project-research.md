# ADR-0080：经典 PDE 完整研究图与显式来源导入

日期：2026-10-29。状态：实现与验收进行中，以本阶段实际回执为准。

将 MRA087 已封存的 pde-language-v1 作为唯一数学执行器，新增 pde-project-research-v1 图协议、独立 artifacts/pde-research 及每图私有子账本；不迁移或改写旧候选图。原 /analysis 仍使用其既有协议，新 /pde 单独接入同一工作台和单 worker。

每图有且仅有一个原问题，最多八节点，全部节点必须通向该问题。保存仅编译完整变量、条件、测度、目标和证明程序，保持 UNKNOWN/E0。depends_on 表示调度与确切证据身份；target.sources 才表示真实证明数据引用，不能以调度前置自动补充逻辑假设。

具名节点预览须从每个实际祖先子账本复核当前完整 E4，严格比较原文、完整请求及形式类型，再把符号来源替换成真实 run ID。提交绑定整个预览指纹与核对人；执行前和发布时再审计，原问题必须有自己的候选检查和独立重放。

复用既有 Lean 4.35.0、固定 Mathlib 56a005855ea17e0b0958f73ec801ae140b0a1679、watched 环境和证明 NDJSON 导入；无新下载或依赖。基础库仍为受信环境，两个进程使用同一 Lean 内核实现。具名身份仍是本地声明。

每图至多16次尝试、480秒合计预留worker预算，单候选及重放共享原有40秒上限。取消和失败仍消耗预留次数与预算。完整性扫描、来源闭包和锁等待额外计时，不承诺硬实时完成。

取消在图发布前提交时，实际子检查即使成功也不得使图晋升。监督退出后须在全局worker锁内保守恢复，只标记中断/取消孤儿，不自动重试。来源损坏、撤销或父语境变化持久停用后继；恢复文件或旧图记录不复活已失效的子证据。

验收须覆盖四步分部积分→Green→Poisson测试恒等式→能量恒等式的真实来源导入、错误原问题、真实成功后的取消及监督退出、来源/图记录恢复、撤销与父语境变化。协议、HTTP和浏览器检查不能替代实际数学执行。测试均为已知作者可见目标，不构成一般弱解、存在唯一性、高维或原创研究能力证据。
