# ADR 0084：为通用研究接入固定 Mathlib 源码检索

日期：2026-10-30。状态：采用。

## 决策

在既有跨领域工作台中加入 Mathlib 源码候选检索、逐步骤引用、撤回和模型上下文接入。使用本地已有 SQLite FTS5，显式中文概念同义词与名称匹配优先级，再按词法 BM25 排序。没有新依赖、模型调用、下载或向远端发送研究内容。

仅索引已封存 Mathlib 树中列出的 `.lean` 源文件，逐文件读取实际字节并核对 SHA-256；环境版本和 Mathlib LICENSE 同样须匹配现有快照。索引器版本、快照和 Mathlib commit 绑定索引身份；索引在临时数据库完整构建、提交后原子替换，失败保留旧库。版本不符时显式拒绝并要求重建，不自动修改基线或重封存。

## 范围与证据

词法提取具名 theorem/lemma/def/abbrev/structure/class，屏蔽嵌套注释和字符串；这不是 Lean 环境的完整声明枚举。保留名称原样书写、文件、模块、声明行号、字节摘要和源码片段，不推断完整限定名或已展开类型。截取的片段可能缺少文件中更早的局部变量、类型类或命名空间语境；必须核对原文件，不能当成完整适用条件。

读取命中或保存引用时重新核对真实源文件与索引条目，防止过期片段、索引损坏或条目身份错配。检索结果和研究引用都保持 UNKNOWN/E0，不执行 Lean，不成为证明依赖或 PROVED 的依据。没有改变原验证器。

## 研究生命周期

引用绑定确切计划和研究步骤；最多12条历史引用。撤回保留原条目，不再传入模型；重新引用需要显式新操作。换计划保留历史但不自动带入旧引用。源码或索引不可用时，原题及研究记录仍可读取，引用显示 UNAVAILABLE，模型只接收不可用说明，不接收失效内容。仍可手动输入研究文字，整个研究问题不会因此晋升证据。

模型后续研究输入加入选定步骤的有效引用，保留原问题、全部定义与假设、此前两轮及验证反馈。预算超限仍拒绝，不以丢弃原条件换取请求成功。当前模型未配置；上下文接入使用标明 fixture 的协议测试，不能视为真实模型研究能力成绩。

## 许可、开销与限制

复用项目已有 Mathlib 4 commit `56a005855ea17e0b0958f73ec801ae140b0a1679`，Apache-2.0；仅作本地研究检索，不导入新的执行权限。SQLite 为既有标准库依赖，public domain。本机实建8624个源文件、230480条具名声明候选，索引697036800字节，约665MiB；名称和源码的检索不等同语义检索或适用性判断。

普通中文仅支持显式列出的概念别名，不是通用自然语言翻译。零命中不证明库中没有结果。作者可见的7个检索示例不是独立 Recall/MRR 评测，不据此给数学求解率。旧scanner及顺序四节点验收失败仍保留。
