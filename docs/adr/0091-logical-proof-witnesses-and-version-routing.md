# ADR 0091：逻辑证人与证明版本路由

日期：2026-10-30。状态：实现；数学结果以本轮实际工件为准。

## 问题

既有语言能陈述存在、析取及蕴含，却缺少完整的证人构造和消去接口。CS等号条件不能用不等式本身替代，也不能无条件改写成“第二个向量是第一个的倍数”：第一个为零、第二个非零时会漏掉合法等号情况。

原文公式2定义为存在不全为零的两个实系数，使两侧数乘相等。需要显式核对它与Mathlib等号准则的双向对应。

## 决定

新增独立 `proof-language-v2` / `proof-project-research-v2`，不修改既有v1编译器、账本或封存运行时。v2增加 `iff`、存在证人/消去、析取分支、经典分情况、顺序已证引理、显式化简，以及固定逻辑和内积等号规则。

所有新绑定拒绝遮蔽已有变量或假设；存在证明在新名字入作用域前编译，分支证据不互通。顺序引理先证明后使用，不允许自引用或前向引用。类型对应仍由真实Lean核验，编译成功不授予数学证据。

v2原始输入仍限制131072字节；为容纳嵌套证人与分支，节点/深度上限改为2400/64，其他类型、变量、假设、标量和预算限制沿用原规则。局部引理最多8项，显式改写最多8项，候选和回放仍共享最多40秒执行预算。

同一 `/proof` 页面、`proof` 后端及 `/v1/proof-research` 接受两个明确版本。新请求按全部节点的显式schema选择验证器，混用/未知版本拒绝，不回退；历史图按严格图ID交给原提供者。v2目录及图前缀独立为 `proof-logic-research` / `proof2flow-*`，子账本身份也独立。

跨版本创建请求共用串行登记。编号绑定完整请求和版本，发布失败可按完全相同请求恢复；不能复用同一编号悄悄另建另一版本。两版工作队列轮流获得调度，仍由原全局worker租约保证只有一个检查器执行。

新生命周期以固定v1实现建立独立文件，逐项审阅差异；这是保留旧身份的维护成本。本轮不对已入证据的共享验证器做公共抽取或缓存改造。新示例仅产生受控请求；完整编译结果及所有数学输入由manifest和检查计划约束，例子本身不授予证据。

## 数学与信任边界

Mathlib `norm_inner_eq_norm_tfae` 的允许实例明确含零向量。结构化证明将 `u=0 ∨ ∃r,v=r•u` 双向转换为 `∃a b,(a≠0 ∨ b≠0) ∧ a•u=b•v`。再利用非负平方的相等条件，证明CS差式的零点等价于这个谓词。

集合X按原文定义逐点展开，ℓ按差式定义展开；没有增加非零、连续或可微前提。局部结果需要真实Lean、独立数据回放、公理/类型/工件审计及具名本地对齐，不能替代全文认证。模型继续不配置。
