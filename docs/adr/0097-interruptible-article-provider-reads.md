# ADR 0097：可中断的文章原证据读取

日期：2026-11-01。状态：采用本轮实现边界；验证结果另存 `artifacts/article-reader-v2-20261101-01/`，本文不提前宣告验收通过。

## 问题

ADR 0096 将文章关联复核改为持久后台任务，但在途原 provider 调用仍位于 worker 线程中。若读取阻塞，协作取消只能等待调用返回，服务关闭也可能长时间等待。需要给默认读取提供独立的执行和退出边界，同时保留原验证器对完整证据的核对，不能通过缓存、减少读取字节或省略完整性检查换取响应速度。

本决策仅替代 ADR 0096 中默认 provider 的在途取消与关闭限制，其历史观察、原文快照、数学判断及证据授权边界继续有效。

## 决定：固定原 provider 在受控子进程中读取

生产默认路径在独立子进程中调用固定的原 provider 报告入口。父进程负责执行期限、输出预算、取消与回收；子进程仍读取原任务图和完整工件，执行原 provider 的实际检查。不得以缓存报告、模型自报、节选文件或已保存的复核观察替代本次读取。worker 的返回协议不开放任意命令执行接口，也不在此路径创建新的 Lean 检查任务。

默认每图读取期限为 300 秒，返回报告协议上限为 16 MiB。预算超出、读取失败或协议无效时，记录该图读取不可用；不截断报告后继续生成匹配观察。此上限约束返回协议，不授权减少原证据检查范围。期限与预算是默认读取器的边界，不构成整篇复核或服务关闭的固定耗时承诺。

实现只使用现有 Python 标准库和项目入口，不新增第三方依赖；本轮新增真实 Lean 执行为 0。已有真实 Lean 工件仍由原 provider 核对，本次进程管理及其测试不产生新的数学证明。

## 取消、关闭与未提交观察

父进程等待期间持续检查持久取消请求和服务停止事件。需要中断时，对本次读取的进程组发出终止信号并回收直接子进程；读取成功返回后、提交观察之前仍重新检查任务、快照和实现身份。未提交的在途观察被丢弃，不能通过超时、取消或重启重新收编。

取消请求按原任务状态机进入 `CANCELLED`。服务关闭导致的未完成任务进入 `INTERRUPTED`，保留此前已提交的历史观察，不自动重试原 provider，也不把关闭恢复成新的排队读取。关闭与最终发布有先后关系，已经合法提交的终态不因随后到来的停止事件被改写。

worker 生命周期的 owner lease 继续覆盖读取、图间间隙和空闲期。默认读取子进程继承 owner 文件描述符，避免父进程异常退出后，在旧读取仍持有所有权时另一个 worker 将其误判为可恢复任务。子进程另设独立 alarm，使期限约束不完全依赖父进程存活；父进程正常结束或中断读取时负责回收，不能只发送信号便声称已退出。

进程组终止覆盖本读取进程组内的成员。主动调用 `setsid`、脱离该组的后代不在此保证范围内；不能把进程组终止描述成对任意后代的完整隔离。当前固定报告路径不创建 Lean 任务，此方案也不承诺未来任意 provider 的进程树都已安全管理。

## 保留原 provider 的诊断行为

原 provider 可能在完整性核对过程中保存失效标记或诊断结果。读取中断不回滚这类已发生的原有副作用，也不恢复旧工件或抹去失败痕迹。丢弃未提交复核观察仅作用于本次后台任务的发布，不等于底层文件系统事务回滚。

后台任务的 `COMPLETED` 仍只表示本次读取计划结束。`MATCHED_AS_OF_CHECK` 仍是对应读取时刻的历史观察，不能授予实时有效状态，也不能写回文章数学判断。`UNAVAILABLE`、中断和取消均不是数学反证。

## 实现身份、升级与注入路径

任务实现指纹纳入默认读取器及其子进程入口。旧任务保留创建时的实现身份；实现不匹配时只作为历史读取，隐藏当前摘要，旧活动任务不能跨实现续跑。升级、回滚或重新启动不得自动改写旧任务、重试已中断读取或重新认可旧数学证据；新复核由显式新建任务表达。

显式注入的 provider 保留其原有进程内调用与中断契约，不冒充具备默认子进程读取器的抢占、期限或进程组管理能力。测试或嵌入调用者需要自行保证该 provider 可退出；此类 provider 阻塞时，关闭等待仍受其自身行为约束。

## 验收范围

后续验收须分别核对完整报告调用、期限与报告预算、取消和关闭的终态、进程回收、owner 继承、实现变化与旧任务保护，且区分测试 fixture 与真实已有证据读取。测试数量、性能和执行时长只能引用实际保存的工件，不能由本决策预先推断。

保全核对使用本轮在应用编辑前捕获的明确基线：402 个源码与采用记录、104 个既有记录、144 个证明文件，以及 33 个明确列出的运行数据库。此范围不等于穷尽仓库内全部历史测试数据库；旧记录与证明必须保留原字节，新复核只允许新增任务目录。验收不得为了通过而重写旧任务、旧证明或基线。
