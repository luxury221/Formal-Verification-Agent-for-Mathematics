# ADR 0103：全文自动处理与人工数学证据分开

- 日期：2026-11-02
- 状态：采用；真实模型论文效果尚未验收

## 问题

导入、原文义务和研究工作台已有工具，但必须逐步人工操作。自动调用旧接口若填造
`reviewer` / `confirmed`，会把机器生成错误地升级为人工语义确认。因此不沿用这种方式。

## 决策

新增独立 `/automation` 与 `/v1/paper-automation`。复用真实文档提取、受控 AST 编译器、固定
Lean 沙箱、精确目标审计与 NDJSON 数据重放；不自动写入原有人工审核账本。

1. 固定源字节、提取版本、实现指纹和调用预算。可以在提取完成前排队；未配置模型则等待。
2. 将全部**已提取文字**按 Unicode 码点分区，包含普通段落、证明、参考文献；模型逐区解释
   数学义务、作者步骤与覆盖情况。引文必须精确匹配固定原文，不能伪造来源或省略分区。
3. 使用单独模型调用核对阅读，再对每项提出 `typed`、`calculus` 或 `proof2` 候选，并核对
   完整原文、AST 和编译命题。此核对可能由同一服务完成，不是独立专家，也不是人工签名。
4. 仅将通过协议及机器语义核对的候选送到固定检查器。实际候选与数据重放使用不同进程；
   新通路使用受监视的 v2 字节扫描器。旧检查器的历史缺陷与封存记录不作改写。
5. 根据协议错误、明确的语义拒绝和真实 Lean 失败做有界修复。原义务不随修复改变。
   缺上下文时索取完整片段；超出上下文预算、语言范围、调用次数或时间预算均报告缺口。
   环境不可用、提供方传输失败和不确定消耗需显式恢复，不隐式重复提交。
6. 每次调用前预留调用次数、最大输出 token、检查时间；预留是上界，不等于账单。
   每次输入、输出、核对和检查记录单独持久化；重启复用已提交的响应，中断不自动重跑。
7. 队列租约和全局检查租约传入子进程；取消只回收本次任务拥有的进程。原文或实现变化
   要求建立新任务，损坏的历史工件不继续展示为可用证据。

## 数学状态

原文始终 `UNKNOWN / E0`，`whole_article_verified=false`。局部的 `KERNEL_CHECKED` 只表示该
形式候选曾通过真实检查与数据重放，不意味着自动提取和形式化忠实于原文。

阅读覆盖只针对已提取文字，不认证 PDF 公式、图表或提取完整性。任务 `COMPLETED` 表示
自动流程结束；不得当作全文正确的结论。新通路没有自动 `PROVED`、`REFUTED` 或人工确认。

## 限制与后续

当前没有接通实际模型配置，不能用协议样例声称论文理解能力。当前验证区分软件流程、
真实内核和真实模型质量三个层次。通用数学语言、跨论文全文检索、视觉公式忠实性以及
经过独立评测的自动语义对齐仍是后续工作。没有新增依赖或改变已有依赖许可。
