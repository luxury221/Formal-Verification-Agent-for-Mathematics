# ADR 0104：全文结构、自适应阅读、逐项对应与预算结算

日期：2026-11-02。状态：采用，仅适用于新建的 `whole-paper-automation-v2` 任务。

## 问题

v1 固定字符分区不能适应数学义务密集的段落；八个布尔核对项无法直接查看每个前提和结论
对应哪段原文与 AST。修复时仅保留原文，还不足以阻止形式目标变化。永久累计最大预留也会
让已经确认只用少量工作时间的检查继续占满预算。

## 决策

1. 固定来源后，生成独立 `structure.json`。记录已有章节范围、配对公式位置、定义/记号候选、
   符号首次出现的位置及明确限制。同名 TeX 标题用来源位置区分。只做文字层次的导航，
   不宣称数学符号的语义作用域、类型或定义已经解析正确。
2. 阅读单元按段落、句子与公式边界优先分区，限制每区八单元、14000 码点，不跨来源/章节。
   密度过高、显式请求或多单元/长片段的尝试耗尽时追加子区；保留父区、理由和来源范围。
   报告只统计叶区，子区必须无损分割父区。每任务最多 512 区、深度 6；不能继续时明确记缺口。
3. 新核对协议要求逐项 `alignments`：来源切片、SHA256、允许的 AST 路径、关系和解释。
   对象、定义、量词与结论按行列项，原始 assumptions 每项单列；前提与已列出的子结论需要
   不重复且穷尽的 AST 对应，形式绑定、自定义定义、`forall`/`exists` 节点必须有对应。
4. 首次形式核对接受后，在启动 Lean 前持久化目标合同。合同含语言、完整语义请求和实际
   编译命题。后续修复只允许改变 proof/strategy 及宿主分配的时间；更换类型、定义、量词、
   前提或目标均拒绝。每次尝试固定其起始合同；恢复时请求指纹和超时政策保持稳定。
5. 新预算账本区分 HELD、SETTLED、UNCERTAIN。响应/回执登记后，在提交响应状态的同一事务
   中按有效回执结算；重复提交必须完全一致。已结算消耗加仍占用额度用于后续准入。
   无回执、传输中断、检查崩溃和 UNAVAILABLE 保留完整预留；不自动重发结果不明的调用。
   实际超支如实计入并停止新工作，不将用量压到上限。累计预留字段仅供历史追踪。
   恢复时复用已提交内核回执前重新核对其工件，损坏时停止，不进入下一项工作。

## 边界与代价

结构索引最多保存 2048 条符号观察、2048 条公式位置和 128 个分隔符问题明细，超限明确记录；
所有提取文字仍保留并进入阅读计划。单次核对最多 128 个结构组件，密集阅读先拆分，过密
形式义务保留缺口。完整上下文和核对矩阵超出输入限额时拒绝，不截掉条件。

这些结构检查不能识别一行自然语言里所有隐含子命题，也不能证明第一次翻译的量词含义正确。
它们提高可审计性并阻止已锁定目标漂移；语义质量仍依赖实际模型与独立标注评测。
当前量词路径清单只细分 `forall`/`exists`；几乎处处的 `ae` 等结构仍随完整目标送模型核对，
不能据此声称所有形式量词都已细分对应。目标合同仍锁定完整请求，包含这些结构。
单独模型调用可用同一服务，不等于独立专家复核。原文始终 `UNKNOWN / E0`、全文未认证。

新核对矩阵增加输出量；每次 audit 预留 16384 输出 token、60 秒，scan 8192/60 秒，
formalize 8192/90 秒。每次工作进程预留不超过 30 整数秒，按可用余额取整。
服务用量和工作时间不是账单，也不覆盖宿主所有开销；活动时间另受总预算限制。

v1 文件保持原样，可读取历史记录，但新版 worker 不接管/恢复旧任务；继续处理需显式新建。
没有重封存运行环境、修改旧编译器、旧扫描器或迁移证明权威。无新依赖。

协议见 [全文自动处理 v2](../protocols/whole-paper-automation-v2.md)，证据范围见
[本轮验收](../evaluation/paper-automation-v2-results.md)。
