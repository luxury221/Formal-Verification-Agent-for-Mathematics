## 功能与数学边界

实验支持原 Nat/gcd/互素结构化语言，保留全部变量、前提、结论和原文。包括零；减法在零处截断；互素用 gcd=1 解释。最多每变量 0–32、5000 组赋值、100000 次语法树运算、256 位中间整数和 0.5 秒协作式求值时间。溢出跳过并计数；输入验证和来源摘要另计。有限域穷尽、超时、赋值耗尽或未命中都不等于猜想成立。

准备需要完整候选赋值，违反任一原前提或未违反结论则拒绝。计划同时展示原命题、封闭实例、全部数值前提及完整否定；以确切指纹和本地核对者声明确认后，才执行真实检查。证明源码由宿主固定生成，输入不接受 proof、任意 Lean 或附加公理；使用内核可检查的 decide，不使用 native_decide。

子检查的 PROVED 对象是完整否定。父报告只在自身 COMPLETED、子检查 E4、对齐与实际工件有效时，才将原猜想标为 REFUTED/E4。其他状态均 UNKNOWN/E0，不把系统故障当数学反例。姓名只作本地语义声明，不是身份认证或独立专家认证。

HTTP 只提供有限实验 POST 和历史 GET；浏览器可探索、导出完整候选、查看 CLI 步骤和实际记录，不能启动 Lean。核验记录位于每次独立目录的 checks 子账本，不新增主业务数据库、不自动进入研究图或知识库。
