## 初次失败与修正

首轮探针五例中，0／1／3成功，幂加法及泛化例基础步因 Nat.rec 未化简而找不到单位元重写模式。追加 dsimp 后的第二轮两例仍失败。两轮全部报告、候选源、日志和修正前版本分别保存在 probe-*、source-before-rec-reduction 和 source-before-fold-equations。

最终使用局部 rfl 证明的真实 recursor 零／后继计算等式进行 simp only，保留原目标与预算；随后两例候选／重放成功。本轮三项真实专项检验最终版本。旧版本探针记录在当前审计中因实现漂移持续失效，不能把历史E4当当前证据。后续恢复旧源码也不复活失效记录。
