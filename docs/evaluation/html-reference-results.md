# HTML 显式引用定位：验收记录

日期：2026-11-02。范围：新导入 HTML 的来源链接、草稿引用和本地导航。
本轮没有调用模型、执行 Lean 或新增数学证明；全文验证始终为 false。

## 交付与边界

论文导入和数学义务预览可查看每条原 HTML 链接的定位结果，跳转到唯一的完整来源片段。
唯一定位的定义可完整引用到未审核草稿；公式和其他命题仅作为来源上下文。
同一完整陈述内的公式引用保留位置，不另列缺失前提。跨文档、重复锚点、
多片段目标和无效链接均明确保留待核对，链接文字不执行、不自动下载。
对象、量词、全部前提和证明依赖仍需语义整理，来源定位不赋予已证状态。

原片段正文、分类、范围和引用字节摘要不变。新组件实现摘要进入提取元数据和草稿计划指纹。
旧导入、义务、人工编辑、审核与证明不自动迁移；要使用新元数据，需显式新建同版原文件导入。
PDF 链接、隐含定义和完整数学依赖尚未自动恢复。

## 既有失败与自审

完整 source 套件的失败是未改动的
`test_streaming_integrity.ScanTests.test_directory_growth_during_hashing_is_rejected`。
本次 100 次独立诊断中，旧版扫描器漏检目录新增 10 次；漏检时前后完整目录元数据戳相同。
这与 [ADR 0078](../adr/0078-watched-integrity-profile.md) 已记录的限制一致，
不能通过测试延时、重跑到绿或调整断言来宣称修复。
本轮保留首次全量失败，不再次运行全量来替换结果。

已有事件监视 v2 使用独立身份及完整终检，本次 source 套件中的 v2 合同通过；
这不修复或认证旧 v1。封存扫描器、采用记录、验证策略及历史证明均未改写。
故本轮引用功能验收通过，但**全量回归不是全绿，旧版缺陷仍在**。

自审重点包括合成解析根与源偏移 0 的节点不能混同、实际 DOM ID 与显示名分开、
内部公式不制造缺失前提、修正后的文字仍需复核原链接，以及超限不截断。
早期验收辅助程序曾让观察 JSON 与运行收据同名，覆盖了两个观察文件；
原日志和隔离输入仍保留，改用不同名字后完整观察保存为 `real-paper-03.json`。
一次人工检查误用 UTF-16 切片读取码点位置；已按 Python 原始切片核查，并有非 BMP 字符合同比对。
这些不作为解析器错误或已通过的数学验证。
