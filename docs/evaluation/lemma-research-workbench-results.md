# MRA076：统一引理研究工作台验收

2026-10-29。本轮将已有 CLI 能力接入同一数学研究工作台：完整目标的有界局部义务规划、完整递归程序检查、独立引理导出、跨任务显式应用。入口为 /typed-research/lemmas，沿用原侧栏与会话；原数域/结构图功能继续保留。本轮未扩展证明语言、修改旧数学目标或重新计算历史成绩。

[设计](../adr/0068-integrated-lemma-research-workbench.md)；[HTTP协议](../protocols/lemma-research-web-v1.md)。

## 可操作范围

先载入作者交换迭代示例或填写完整结构化目标，规划最多两个候选。选择路线后，预览全部变量、共享定义、原条件、局部义务及完整 Lean 类型；填写核对人并确认预算，后台才执行候选与独立重放。全部义务与主目标共享同一检查预算。

完整 E4 父证明可选择局部引理，填写新的独立标题/语义描述，重新预览和真实检查。导出保留父环境、全部原变量和原条件。跨任务应用要求显式 terms/proofs，实际导入已有证明数据，另行检查和重放完整新目标。来源链固定为父程序→独立导出→应用；应用不可再作为来源。

编辑或切换清除旧确认，晚回应按 epoch 丢弃。全部 POST 单次发送；未知传输结果保留原信封，允许按相同请求ID手动重发。页面提供历史重读、实际完整JSON下载、取消和具名撤销。服务新增三类队列，仍共用原 worker 锁；启动会处理已确认QUEUED，旧RUNNING只恢复为INTERRUPTED/UNKNOWN。

## 保全与边界

[停写保全记录](../../artifacts/structure-lemma-workbench-20261029-01/preservation-final.json)保存基线512来源文件、426旧数据库及777旧状态文件的核对；只允许三个canonical库追加本轮新任务，旧行逐行保持。84个旧数学/策略/题集等核心文件冻结；继承清单中的HTTP/原页面JS因本轮集成单独review，不能同时计作未改文件。新增私有库、状态、canonical证明工件和验证脚本一起封存。实际恢复覆盖旧数据未执行，不作恢复演练声明；服务资源与实际资产字节见本阶段runtime-check及windows-check记录。

本轮模型调用和新增外部依赖均0。示例由项目作者编写且开发者已查看，不是模型输出、盲测或数学新颖性证据。只有固定Type载体、显式运算/闭合定律/受控递推；复用要求相同载体/运算/定义。新流程独立于旧项目图，不自动绑定、晋升原问题；原结构图仍用v3。

具名确认仍为本地声明，双进程仍是同一固定Lean内核实现；检查器不保证原条件一致、自然语言对齐或新颖性。完整性复核/等待另计，当前读取较慢；不因体验需求跳过来源审计。下一步应增加有明确出处和曝光记录的新目标、改善保留全部条件的引理发现/匹配，并测量实际求解收益。该工作台尚不能据此宣称解决四大期刊级开放问题。
