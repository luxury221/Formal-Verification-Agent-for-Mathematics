# MRA063：结构证明复用网页与后台集成验收

本阶段把 MRA062 的实际结构证明项复用接入现有数学研究页和原单 worker；没有新增数学执行器、Lean导入、公理、第三方依赖、模型或训练。原结构图与组合各自拥有运行状态和数学判断，组合结果不能自动晋升原图。

## 用户可执行的流程

在 /typed-research 的“结构与归纳”模式打开已保存任务。上方原图检查建立根来源；下方同一复用面板选择每个直接前置的当前 E4 原图检查或组合记录，填写别名、完整 terms、每条 proofs 及受控 congr／trans。页面显示完整载体、运算签名、定义正文、全部原条件、完整 Lean 类型、每个环境实参、变量替换及对应条件证明。

预览不执行 Lean，始终 UNKNOWN/E0。具名核对后提交一次新组合，由后台串行执行真实证明数据导入、候选类型／公理审计、不同 PID 的独立数据重放。可以读取历史、取消、具名撤销及下载完整 JSON。

模式、图、节点、编辑和核对人变化均清除旧确认；迟到响应不能恢复旧语境。POST不自动重发；已接受但响应丢失时锁定原正文、姓名和确认框，人工原ID原正文恢复。跨刷新草稿尚未持久化，刷新后应先检查历史。

## 自审与保全

逐项核对完整结构类型、源导入、候选和重放公理、PID及原图独立判断；36份冻结数学核心保持原字节。停止态基线426份源中415份不变，11处修改仅HTTP接线、共享目录／网页与五份living文档；375份旧数据库原行与481份旧状态保持，3份新库和14份新状态有停止态快照／备份。父库各追加2行，旧活动复用库追加5行，31468份旧摘要索引按封存规则复核。停止态基线保留代码、数据库行和旧状态文件。父研究库只追加本阶段项目；既有活动结构复用库仅追加本阶段组合，原行与旧封存快照一致。活动数据库追加后原文件摘要会变化，旧索引通过原封存备份与原行核对保全，不声称所有旧活动库字节相同。未进行实际恢复。

## 边界与下一步

来源与目标环境必须逐字相同；不支持跨载体重命名或任意新归纳。完整八条条件需要滚动核对，尚无独立可用性／无障碍审计。浏览器CDP共观察79条实际503响应（不含合成fetch失败与直接Node轮询），恢复动作按原日志保留。完整审计存在真实503与锁等待，GET有界重读、POST仅人工恢复；没有性能收益或无等待声明。页底沿用的“前置只调度”边界指原图，上方／下方的原图和显式组合是不同检查。

作者可见样例用于机制验收；本地姓名只是声明，两进程使用同一固定内核。没有模型调用、前提一致性／结构存在性证明、独立持出题集、原创性或四大期刊能力证据。下一优先是选择明确领域任务并记录曝光与失败／未知全分母，按固定总预算比较复用的实际用途。
