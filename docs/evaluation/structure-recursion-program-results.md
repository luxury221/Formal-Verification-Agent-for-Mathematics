## 实现与可信边界

新增 structure-recursion-program-v1：主目标及全部原环境、变量、定义、条件保持；最多两个局部引理必须依次真实证明，只能调用先前引理。每个引理继承全部原条件，完整主命题不增加引理假设。当前带引理时要求原条件对目标变量闭合。引理继承的 original 文本仅标示主问题语境，以其显式 goal 和完整形式类型为准。

加入固定 Nat.zero_add、Nat.succ_add 等算术规则；每个主证明或局部引理可做一次 Nat 归纳。自动建议只识别显式闭合交换等式与两参数一元原始 fold，提出交换函数穿过 fold 的中间义务。自动候选最多一个引理，手工程序最多两个。没有任意 Lean、额外 import 或自定义 tactic。局部引理没有独立持久 E4 来源，尚不能跨图直接复用。

所有局部义务及主证明合并为同一个候选，在一个共享 worker 预算内接受原执行器检查及不同进程的证明数据重放。完整类型、公理政策、原工件及当前来源身份门禁沿用；同一 Lean 内核实现的双进程重放不是第二个内核。符号建议和父诊断始终 UNKNOWN/E0。

自动合成默认2候选、800展开、4改写，所有引理与主搜索共享展开、归一化节点与0.75秒检查点计时；最后编译和完整性准备没有端到端硬时限。详见[ADR0065](../adr/0065-checked-local-recursion-obligations.md)与[协议](../protocols/structure-recursion-program-v1.md)。无新外部依赖。固定 Lean4.35.0 运行时本地 Apache-2.0 许可和 Nat 源字节核查见 dependency-review.json；没有新增上游真实性声明。

## 数据、曝光及初始失败

六题在首个真实结果前冻结：两道沿用旧公开来源障碍，四道作者构造的相关机制或删条件对照。Mathlib 来源 commit 为56a005855ea17e0b0958f73ec801ae140b0a1679；显式 Type0/Nat.rec 适配尚无与上游 iterate 的内核等价桥接。开发者见过公开陈述及相邻证明，生成器未接收参考证明；不是盲测、独立留出集或原创研究评估。

双组按题交替先后，每题每组最多2候选、每候选与重放共享20 worker秒；24槽名义预留480 worker秒。仅当前完整 E4 后跳过余槽；全部失败保留。准备、合成、完整性审计另计，不能据 worker 时间推一般提速。

首次13协议测试12过1失败，断言错误地期待无 Nat 标注的源码字符串；改为核查错误引理 AST 完整保留。初始静态检查问题及修前代码均保留。

首次真实 validation-real-c7a11b1754b647f5bc101afcf6dc727f 为3项2过1失败（283.589秒）；六题旧v4为1/6、新程序为3/6，交换复合仍拒绝。实际 Lean 日志暴露新编译器错误：无变化的 simp 报失败、helper 包装把 let 定义误作参数、归纳前全局化简提前消耗 recursor 计算引理。修复为允许无变化的固定规范化、引入 helper 变量前展开 let、在归纳分支内规范。未改六题目标、候选请求程序、合成算法或预算。

另有我写的首轮比较摘要过早记录 all_passed=true，尚未检查两项功能验收；外层测试明确失败，才是当轮验收依据。原摘要未重写；initial-real-review.json 明示此错误。当前测试先计算 required_goals 后写摘要。初轮22条已提交结果加1条监督退出记录及29个 worker 阶段完整保留，仅作历史证据，不能冒称当前 E4。
