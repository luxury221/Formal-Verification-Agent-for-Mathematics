## 最小值

```json
{"is_minimum":{"function":{"lambda":{"name":"t","type":"Real","body":{"pow":[{"var":"t"},2]}}},"value":{"real":[0,1]}}}
```

表示 `∃t:ℝ,f(t)=m` 与 `∀t:ℝ,m≤f(t)` 的合取。示例只是公式输入，保存或编译不授予证明。定义域目前是全部实数；不接受 domain、infimum、默认值或 assume_attained 字段。

## 固定规则

| 规则 | 项 | 证明参数 | 数学结论 |
| --- | --- | --- | --- |
| `least_squares_minimum` | 同空间向量 u,v | 无 | `‖u‖²−|⟨u,v⟩|²/‖v‖²` 是 `‖u−βv‖²` 取得的全局最小值，并给出加权差式恒等式 |
| `least_squares_derivative` | u,v,实数 β | 无 | 平方距离在 β 处的精确 HasDerivAt |
| `least_squares_stationary` | u,v,实数 β | v≠0 的已证事实 | 导数为零推出 β 为投影商 |

新增固定改写 `norm_sub_rev`、`real_inner_comm`。其余有类型表达式、固定规则和逻辑构造继承 v2，不接受任意 Lean/imports/公理。最小二乘规则包含零向量分支；驻点规则要求显式非零证明。内置例子保留论文原前提，即使某个固定定理可证明更强结果，也不删原条件。

`steps`/`have` 的已证引理可被后续证明复用；名字只能在规定作用域中使用。通用最小二乘局部定理在同一空间内共享一次，所有定义和证明仍随本次工件导出，不是跳过验证或直接信任候选结果。
