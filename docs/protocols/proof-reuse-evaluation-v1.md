# proof-reuse-evaluation-v1

本协议在首次执行前固定。五题为：重复整除引理、完整互素前提、错误前提、来源不可用、展开结构超限。所有输入及程序由项目作者编写并查看，禁止训练用途；不是持出或盲测。

- 每题一个受控 Nat 前置程序和一个完整目标；前置程序不含私有引理。两组获得完全相同的前置程序、全部条件及基础引用。
- import 构建一次前置完整 E4，再导入其 replay/proof.ndjson 并检查完整目标、独立重放。来源不可用题不构建前置。
- inline 按调用实参同时替换前置程序的全部自由变量和全部前提；不递归替换已插入的实参。保留目标原文、变量顺序、全部前提和结论；编译器限制保持不变。
- 每题每组同为最多 2 次完整检查、60 秒 worker；单次 30 秒，完整性扫描和初始化额外计时，分别报告。固定程序不能重试、换证明或挪用剩余预算。import 每题最多前置与目标各一次，inline 仅展开目标一次。
- 实际合计最多 15 次检查、450 秒 worker；单组额度 300 秒。完整性及文件锁等待没有硬实时上界，不宣称墙钟超时保证。
- 每题先处理来源，再按题序交替 import/inline 的目标检查顺序。五题始终进入分母；错误证明、结构阻塞、来源不可用和超时均 UNKNOWN。拒绝证明不等于 REFUTED。
- 同时报出各组 PROVED/E4、UNKNOWN、REJECTED、SOURCE_UNAVAILABLE、STRUCTURE_BLOCKED、实际进程数、保守预留额度、worker 时间、检查总时间和整轮墙钟。import 冷启动含来源构建；目标成本单列，不用暖启动数字冒充冷启动收益。
- 展示每题配对状态及 import−inline 时间差。展开超限的 import 独有通过只解释为当前结构限制，不能解释为数学求解改善；无重复、误差区间或显著性推断。

CLI：`reuse-evaluation-prepare` 保存预审（UNKNOWN/E0、无 Lean）；`reuse-evaluation-run ID --plan-fingerprint HASH --reviewer NAME --confirmed` 执行；`reuse-evaluation-report ID` 复核并导出 JSON。重复 run 只读原结果，不恢复或重试。无新增 HTTP 自动执行或后台队列。

每轮独立 SQLite；来源身份由同轮已提交真实检查报告解析，必须完整匹配预审的源程序、所有目标字段、具名审核、工件摘要及两进程审计。损坏／撤销／实现变化停用整轮统计并写持久标记。中断不统计成功率、不自动采用未提交子结果。所有数学证据仍来自同一固定 Lean 内核实现的不同进程，本地姓名不等于认证身份。
