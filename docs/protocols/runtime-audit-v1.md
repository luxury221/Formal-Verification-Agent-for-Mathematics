# buffered-full-content-audit-v1

命令：`python3 -m mra runtime-audit`。默认单线程，可显式使用 `--workers 2` 或 `--workers 4`。线程选项用于诊断，不代表更快。

命令重新加载现有封存，逐次读取 Lean／Mathlib 安装树的全部覆盖文件，比较 SHA-256、模式、目录与链接记录；另核对固定文件、宿主依赖、快照及本机锁。递归排除 `.git` 与原扫描一致。文件打开前后、读取后及最终路径使用相同 stamp 检查，O_NOFOLLOW 保持；不使用大小／mtime 或先前摘要跳过读取。

临时缓冲区每线程 1 MiB，只将本次 readinto 返回的字节加入哈希；短文件、空文件不会混入上一次尾部。线程上限 4、每批最多 64 文件，任意失败不返回完整成功统计。默认数学验证器继续使用原扫描，本命令不启动 Lean，也不改变运行环境封存。

输出包含运行状态、`observed_integrity_ok`、运行树的条目／文件／字节数、各树记录摘要、固定／宿主文件数量、实现摘要和时间。结果保存至 `artifacts/runtime-audits/audit-ID/report.json`，最多 100 份本地诊断。成功退出码 0；策略／内容失败为 2，保持 UNKNOWN/E0 且没有成功统计。错误参数及路径重定向拒绝。

所有结果均为诊断：`math_verdict=UNKNOWN`、`evidence_level=E0`、`lean_calls=0`、`model_calls=0`。保存的 JSON 只描述当次观察，不能据历史记录声称当前环境仍完整，也不能代替候选检查、独立重放或语义对齐。没有签名／身份认证／不可变存储保证，宿主与文件系统仍受信；扫描与执行不是原子事务。

性能比较要记录首次预热、交替顺序、所有样本及实现摘要，区分剖析记录和未剖析计时；单次整树扫描收益不等于完整数学任务提速，更不等于模型／研究能力改善。
