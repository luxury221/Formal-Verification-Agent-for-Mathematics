# 全文自动处理 v2

新建任务使用 `whole-paper-automation-v2`。入口仍为 `/automation`，HTTP 路由和创建、取消、恢复的
请求字段沿用 [v1 接口](whole-paper-automation-v1.md)。API 路径中的 `/v1/` 与持久化任务版本独立。
模型配置、真实环境准备和同源写入保护不变。未配置模型时只保存来源、结构和未完成覆盖。

## 结构和自适应阅读

`source.json` 固定完整提取结果；`structure.json` 保存章节范围、公式位置、定义候选及符号位置。
符号是文字匹配候选，每片段同名符号只记录首次位置，不认证数学定义或语义作用域。
索引达到数量限制时报告具体限制，原文不会因此截断。前端“结构与符号”可跳转回完整片段。

每个初始阅读区包含不跨章节的紧凑 `focus` 引用。长片段优先沿句子、段落及公式外部边界切分；
局部单元还提供完整原片段作为上下文，无法完整装入时明确失败。相关定义按章节/符号候选提供，
未提供的可选上下文逐项列在 `omitted_context`，模型可请求补充。

模型可返回：

```json
{"action":"SPLIT","source_fingerprint":"输入指纹","reason":"该区包含过多相互独立的推理"}
```

宿主决定实际分割，不接受模型替换原文。返回超过八个义务、核对组件过多也会触发拆分；
多单元或超过 4000 码点的片段用尽尝试后可继续拆分，短单元则保留缺口。
父区 `SPLIT`、子区编号及范围持久化，恢复后可继续发现新子区。进度与覆盖按当前叶区统计，
不会重复计算父区。最多 512 区、深度 6；初始计划超限明确拒绝，不截断来源。

## 逐项对应和目标合同

阅读结果中的对象、定义、量词、结论按非空行生成组件；原始 assumptions 的每项分别生成组件。
这是结构清单，不能自动找出所有自然语言隐含命题。阅读核对还要求每个 focus 单元的对应。

核对请求提供 `alignment_requirements`。响应除原八个检查和问题外必须给出：

```json
{"alignments":[{"id":"conclusion:0:0","source_refs":[{"block_id":"block-0001","span":[0,12],"slice_sha256":"请求提供的原切片哈希"}],"formal_paths":["/request/goal"],"relation":"MATCH","explanation":"具体说明原结论如何对应此目标"}]}
```

示例仅展示新增字段，不是完整响应。来源索引是完整 block 的 Unicode 码点下标，哈希对应精确
UTF-8 切片。宿主拒绝外来/重复/缺失组件、错误切片、未登记 AST 路径和未解决的接受行。
形式前提和已列出的子结论必须分别穷尽、不重复地对应；绑定、定义与显式量词不得漏配。
这不代表模型解释已经被数学证明；初次含义错译仍需语义审查和独立金标准发现。

首次接受后保存 `target_contract`，包含精确编译目标和语义请求。后续输入带 `locked_target`，
只允许修复 proof/strategy。改变对象类型、量词、定义、前提或结论会在再次核对/执行前拒绝。
`component_audit`、`locked_target`、`reading_audits` 在详细报告与导出中可查看。

## 预算与中断

`accounting_schema=paper-budget-settlement-v1`，每个操作有唯一 reservation。资源状态为
HELD、SETTLED 或 UNCERTAIN；`accounting` 给出 settled、held、uncertain、occupied，
其中 uncertain 是 held 的子集，occupied=settled+held。

- 模型调用数先计入，不退回。有效响应的 output token 按服务报告结算；不是价格或账单。
- 正常完成或检查失败的有效内核回执按 worker_seconds 结算；环境不可用、损坏回执或中断不退预留。
- 后续准入使用已结算消耗与仍占用额度，累计 `*_reserved` 仅是历史字段，可大于总预算。
- 结算与响应状态、active 清除同事务提交；已提交模型响应/内核回执恢复时复用，不重复占用。
- 不确定调用保留原预留；显式恢复只能进入下一次有限尝试，不隐式重发同一调用。
- 确认超支按真实记录计入并停止新工作。整数秒检查预算不足一秒时停止，不向上超额取整。

旧 v1 任务不会被改写、自动接管或在新实现下恢复。历史记录可读；新版处理需新建任务。
取消、预算耗尽、流程完成和数学判断分别记录。即使所有形式候选通过，原文仍为 `UNKNOWN/E0`，
`whole_article_verified=false`。真实 LLM 全文质量需要另行验收。
