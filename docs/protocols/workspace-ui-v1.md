## 浏览器本地草稿

论文页支持不超过 2 MB 的 txt、md、tex 文本，最多保留 200000 字符；审查笔记最多 20000 字符。内容在当前标签页的浏览器会话保存，不发送给后端或模型，不执行其中的标记或命令。关闭会话会丢失本地草稿；需要长期保存应自行保留原文。这里没有自动命题提取、审稿或 PDF 解析。

“在猜想探索中研究”只将当前草稿前 8000 字符带到原文输入框；原文示例则带入该示例命题。用户仍需检查、编辑并提交，不能将此动作视作完成数学审查。

页面下方的“单定理审查”使用独立的结构化标注，不自动读取上方草稿。准备时标注送往本机接口，确认后原文、标注与检查记录持久保存在 `artifacts/paper-reviews/reviews.sqlite3`；不调用模型。完整义务、双通道判断与范围见 [审查协议](paper-review-v1.md)。

设置页面仅生成配置 JSON。完整地址需满足现有配置约束，模型与部署标识不得为空，部署标识不能为 latest/main 等浮动值。配置文件仍须由用户放到 `config/model.local.json`；密钥通过服务启动环境指定，更改后重启。生成内容不会连接模型或启用生成。

## 只读评测接口

| 方法 / 路由 | 行为 |
| --- | --- |
| GET `/v1/evaluations` | 默认回归组真实计划、数据拆分数量、最多二十条评测执行元数据 |
| GET `/v1/evaluations/{id}` | 通过原 `read_model_evaluation` 核对该轮工件并返回历史报告 |

列表只含 ID、状态、创建时间、simulation、进度与配置模型名称，不含求解率或数学标签。缺文件、坏 JSON、超 1 MiB 或字段类型/范围错误的列表条目跳过。ID 只接受 `nat-plans-` 加三十二位小写十六进制，拒绝符号链接和越界路径。详情工件不完整时 `integrity_ok=false`、`model_solve_rate=null`；界面不显示失效结果。

fixture 明确标为“接口模拟 · 非模型分数”，不显示模拟模型求解率。历史摘要一致也不是当前环境重新认证。预留组命令显式带 `--include-reserved`，并说明作者已查看、不是独立盲测。页面没有 HTTP 评测执行、配置写入、密钥保存或供应商连通性接口。

全部路由沿用 [HTTP 工作台协议](http-workbench-v1.md) 的 Host/Origin/CSP/no-store 规则。真实猜想流程见 [猜想协议](ideas-v1.md)，评测预算和数据语义见 [模型评测协议](model-evaluation-v1.md)。
