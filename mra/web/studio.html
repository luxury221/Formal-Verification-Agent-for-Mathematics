人工研究 · 推演与结构化候选

无需配置模型。先记录这一研究步骤的论证，再按现有验证语言粘贴完整候选。保存仍为 UNKNOWN / E0。

可选：完整形式化候选 JSON

填写 {backend, request} 或 null。backend 可取 proof、typed、calculus 或 pde。proof 支持有限 ℓp / 实幂及历史证明语言。request 中唯一 problem 节点的 target.original 必须逐字等于上方所选步骤。无法忠实表示的目标保留为缺口。

04 / REVIEW THE EXACT TARGET

核对完整形式化候选

确认原题、定义、全部假设及当前步骤与形式化命题对应。保存后进入已有验证器，再确认执行；这里不会启动 Lean。

研究可以跨越领域。每一条形式化结论，都对应一个明确、可检查的命题。
